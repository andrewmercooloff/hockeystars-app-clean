# Исправление отступа нижнего меню на Android

## 🐛 **Проблема**
Нижнее меню приложения (таб-бар) оставляло отступ снизу для системного меню Android, хотя системное меню скрыто.

## 🔍 **Причина**
В стилях таб-бара был установлен `paddingBottom: 10`, который создавал отступ снизу для системной панели навигации.

## ✅ **Исправление**

### Изменен стиль таб-бара в `app/_layout.tsx`:
```typescript
tabBarStyle: { 
  backgroundColor: '#000', 
  borderTopWidth: 0,
  height: 80,
  paddingBottom: Platform.OS === 'android' ? 0 : 10, // Убираем отступ снизу для Android
  paddingTop: 10
},
```

### Логика исправления:
- **Android**: `paddingBottom: 0` - нет отступа, так как системное меню скрыто
- **iOS**: `paddingBottom: 10` - сохраняем отступ для iOS

## 🎯 **Результат**

### Теперь на Android:
- ✅ **Таб-бар прижат к самому низу** экрана
- ✅ **Нет лишнего отступа** снизу
- ✅ **Максимальное использование** пространства экрана
- ✅ **iOS остается без изменений**

## 🧪 **Тестирование**

1. **Откройте приложение** на Android устройстве
2. **Проверьте нижнее меню** - оно должно быть в самом низу
3. **Убедитесь, что нет отступа** между таб-баром и нижним краем экрана
4. **Проверьте на iOS** - отступ должен остаться

## 📱 **Контекст**

Системное меню Android скрывается через:
```typescript
await NavigationBar.setVisibilityAsync('hidden');
await NavigationBar.setBehaviorAsync('overlay-swipe');
```

Поэтому приложение занимает весь экран, и отступы для системного меню не нужны.

Теперь нижнее меню должно быть прижато к самому низу экрана на Android! 🚀
