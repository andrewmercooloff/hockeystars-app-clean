# Оптимизация производительности шайб для старых Android устройств

## 🐛 **Проблема**
На старых Android устройствах шайбы движутся дерганно и не плавно из-за высокой частоты обновления анимации.

## ✅ **Решение**
Оптимизация частоты обновления и сглаживание движения для лучшей производительности на слабых устройствах.

## 🔧 **Технические изменения**

### **1. Частота обновления анимации:**
```typescript
// Было:
}, Platform.OS === 'ios' ? 8 : 16); // iOS - 120 FPS, Android/Web - 60 FPS

// Стало:
}, Platform.OS === 'ios' ? 8 : (Platform.OS === 'android' ? 33 : 16)); // iOS - 120 FPS, Android - 30 FPS, Web - 60 FPS
```
- **Android:** 16ms → 33ms (60 FPS → 30 FPS)
- **Результат:** Снижена нагрузка на процессор в 2 раза

### **2. Throttling для перетаскивания:**
```typescript
// Было:
if (now - lastUpdateTimeRef.current < 16) {
  return;
}

// Стало:
const throttleInterval = Platform.OS === 'android' ? 33 : 16;
if (now - lastUpdateTimeRef.current < throttleInterval) {
  return;
}
```
- **Android:** 16ms → 33ms throttling
- **Результат:** Более плавное перетаскивание

### **3. Сглаживание скорости при перетаскивании:**
```typescript
// Было:
const vx = (newX - lastPositionRef.current.x) * 0.8;
const vy = (newY - lastPositionRef.current.y) * 0.8;

// Стало:
const speedMultiplier = Platform.OS === 'android' ? 0.5 : 0.8;
const vx = (newX - lastPositionRef.current.x) * speedMultiplier;
const vy = (newY - lastPositionRef.current.y) * speedMultiplier;
```
- **Android:** 0.8 → 0.5 коэффициент скорости
- **Результат:** Более плавное движение при перетаскивании

### **4. Сглаживание финального импульса:**
```typescript
// Было:
const finalVx = dragVelocityRef.current.vx * 0.5;
const finalVy = dragVelocityRef.current.vy * 0.5;

// Стало:
const impulseMultiplier = Platform.OS === 'android' ? 0.3 : 0.5;
const finalVx = dragVelocityRef.current.vx * impulseMultiplier;
const finalVy = dragVelocityRef.current.vy * impulseMultiplier;
```
- **Android:** 0.5 → 0.3 коэффициент импульса
- **Результат:** Более мягкое движение после отпускания

### **5. Дополнительные оптимизации скорости:**
```typescript
// Начальная скорость:
```

## 🎯 **Результат**

### **До оптимизации:**
- Частота обновления: 60 FPS (16ms)
- Дерганное движение на старых устройствах
- Высокая нагрузка на процессор
- Неплавное перетаскивание

### **После оптимизации:**
- Частота обновления: 30 FPS (33ms) для Android
- Плавное движение на всех устройствах
- Снижена нагрузка на процессор в 2 раза
- Сглаженное перетаскивание
