# Как проверить статус сборки EAS

Если компьютер выключился после отправки запроса на сборку, вы можете проверить статус несколькими способами:

## 🌐 Способ 1: Через веб-интерфейс Expo (самый простой)

### Прямая ссылка на ваш проект:
```
https://expo.dev/accounts/[ваш-аккаунт]/projects/hockeystars/builds
```

### Как найти:
1. Откройте браузер
2. Перейдите на https://expo.dev
3. Войдите в свой аккаунт
4. Перейдите в раздел **Projects** → **hockeystars**
5. Выберите вкладку **Builds**

### Что вы увидите:
- ✅ Список всех сборок (последние сверху)
- ✅ Статус каждой сборки:
  - **in-progress** - сборка выполняется
  - **finished** - сборка завершена успешно
  - **errored** - ошибка при сборке
  - **canceled** - сборка отменена
- ✅ Платформа (iOS/Android)
- ✅ Версия приложения
- ✅ Время создания и завершения
- ✅ Ссылка на скачивание (если готова)

## 💻 Способ 2: Через командную строку

### Проверить все сборки:
```bash
eas build:list
```

### Проверить только iOS сборки:
```bash
eas build:list --platform ios
```

### Проверить только Android сборки:
```bash
eas build:list --platform android
```

### Проверить последние 5 сборок:
```bash
eas build:list --limit 5
```

### Проверить статус конкретной сборки:
```bash
eas build:view [BUILD_ID]
```

**Где взять BUILD_ID?**
- Из веб-интерфейса Expo (см. Способ 1)
- Из вывода команды `eas build:list`

## 📱 Способ 3: Через мобильное приложение Expo Go

1. Установите приложение **Expo Go** на телефон
2. Войдите в свой аккаунт
3. Перейдите в раздел **Projects**
4. Выберите проект **hockeystars**
5. Просмотрите статус сборок

## 🔍 Что означают статусы:

- **in-progress** ⏳ - сборка выполняется (обычно 15-30 минут)
- **finished** ✅ - сборка завершена успешно, можно скачать
- **errored** ❌ - произошла ошибка, проверьте логи
- **canceled** 🚫 - сборка была отменена
- **pending** ⏸️ - сборка в очереди, ожидает начала

## 📊 Дополнительная информация:

### Если сборка завершена (finished):
- **iOS:** Сборка автоматически отправляется в TestFlight (если использовали `--auto-submit`)
- **Android:** Сборка готова к загрузке в Google Play Console

### Если сборка с ошибкой (errored):
1. Откройте детали сборки в веб-интерфейсе
2. Просмотрите логи ошибки
3. Исправьте проблему
4. Запустите новую сборку

### Если сборка долго выполняется:
- Обычное время сборки: **15-30 минут**
- Если больше часа - возможно проблема, проверьте логи
- Можно отменить и запустить заново
