# Проверка настроек Supabase Realtime

## 🔍 **Проблема**
Push-уведомления для сообщений не работают, возможно из-за настроек Supabase.

## 📋 **План проверки**

### 1. **Запустите SQL скрипт**
```sql
-- Запустите в Supabase SQL Editor
\i check_supabase_realtime.sql
```

### 2. **Проверьте результаты:**

#### A. **Realtime включен для таблицы messages?**
Должно быть:
```
tablename: messages
relreplident: d (default) или f (full)
```

#### B. **Есть ли публикация Realtime?**
Должно быть что-то вроде:
```
pubname: supabase_realtime
puballtables: true
```

#### C. **Таблица messages подписана на публикацию?**
Должно быть:
```
pubname: supabase_realtime
table_name: messages
```

### 3. **Если Realtime не настроен:**

#### Включить Realtime для таблицы messages:
```sql
-- Включить Realtime для таблицы messages
ALTER PUBLICATION supabase_realtime ADD TABLE messages;
```

#### Проверить RLS политики:
```sql
-- Проверить RLS политики
SELECT * FROM pg_policies WHERE tablename = 'messages';
```

### 4. **Проверьте логи Supabase**
В Supabase Dashboard:
- **Logs** → **Realtime**
- Ищите ошибки при отправке сообщений

## ✅ **Альтернативное решение**

Я добавил **прямую отправку push-уведомлений** в функцию `sendMessageSimple`. Теперь push отправляется сразу при сохранении сообщения, не дожидаясь Realtime.

### Ожидаемые логи:
```
📨 ОТПРАВКА СООБЩЕНИЯ: {...}
📱 Push токены для получателя 3cd6dfc5-699b-4770-90cb-572edd39a9f3: 1
📱 Отправляем push о сообщении от ADMIN для пользователя 3cd6dfc5-699b-4770-90cb-572edd39a9f3
📱 PUSH: Отправляем уведомление о сообщении
```

## 🧪 **Тестирование**

1. **Отправьте сообщение** с Android устройства
2. **Проверьте логи** - должны появиться новые сообщения о push
3. **Проверьте push-уведомление** на iOS устройстве

### Если push все еще не приходит:
1. **Проверьте push-токены** получателя
2. **Убедитесь, что получатель использует development build** (не Expo Go)
3. **Проверьте настройки уведомлений** на устройстве

## 🚀 **Преимущества нового подхода**

1. **Независимость от Realtime** - push отправляется сразу
2. **Надежность** - не зависит от настроек Supabase
3. **Простота** - меньше компонентов, которые могут сломаться
4. **Диагностика** - подробные логи на каждом этапе

Теперь push-уведомления должны работать независимо от настроек Realtime! 🚀
