# Deep Links для Push-уведомлений

## 🎯 **Цель**
Реализовать глубокие ссылки (deep links) для push-уведомлений, чтобы пользователь переходил именно к нужному месту в приложении при нажатии на уведомление.

## ✅ **Реализованные Deep Links**

### **1. Уведомления о сообщениях**
```typescript
// utils/notificationService.ts
deepLink: `/chat/${senderId}`
```
- **Действие:** Переход в чат с отправителем
- **Пример:** `/chat/1bc22582-30bf-4375-9c0b-ac6132542094`

### **2. Уведомления о статистике**
```typescript
// utils/playerStorage.ts
deepLink: `/player/${playerId}`
```
- **Действие:** Переход к профилю игрока
- **Пример:** `/player/1bc22582-30bf-4375-9c0b-ac6132542094`

### **3. Уведомления о подарках**
```typescript
// utils/notificationService.ts
deepLink: '/gifts'
```
- **Действие:** Переход к разделу подарков
- **Пример:** `/gifts`

### **4. Уведомления о дружбе**
```typescript
// utils/notificationService.ts
deepLink: '/friends'
```
- **Действие:** Переход к разделу друзей
- **Пример:** `/friends`

## 🔧 **Техническая реализация**

### **1. Отправка уведомлений с deep links**

#### **Сообщения:**
```typescript
await sendMessageNotification(
  receiverTokens,
  senderPlayer.name || 'Пользователь',
  text,
  senderId
);

// Внутри функции:
sendPushNotification(token, title, body, {
  type: 'message',
  senderId,
  action: 'open_chat',
  deepLink: `/chat/${senderId}` // ← Deep link
});
```

#### **Статистика:**
```typescript
await sendNotificationToUser(
  userId,
  title,
  body,
  {
    type: notificationType,
    player_id: playerId,
    action: 'open_profile',
    deepLink: `/player/${playerId}` // ← Deep link
  }
);
```

### **2. Обработка deep links в приложении**

#### **Обработчик в _layout.tsx:**
```typescript
React.useEffect(() => {
  const notificationListener = Notifications.addNotificationResponseReceivedListener(response => {
    const data = response.notification.request.content.data;
    const deepLink = data?.deepLink;
    
    if (deepLink) {
      console.log('🔗 Deep link из уведомления:', deepLink);
      
      // Небольшая задержка для завершения навигации
      setTimeout(() => {
        router.push(deepLink as any);
      }, 500);
    }
  });

  return () => notificationListener.remove();
}, []);
```

## 🎯 **Пользовательский опыт**

### **До реализации:**
1. Пользователь получает push-уведомление
2. Нажимает на уведомление
3. Приложение открывается на главном экране
4. Пользователь вручную ищет нужный раздел

### **После реализации:**
1. Пользователь получает push-уведомление
2. Нажимает на уведомление
3. Приложение открывается **прямо в нужном месте**:
   - 💬 **Сообщение** → Открывается чат с отправителем
   - 📊 **Статистика** → Открывается профиль игрока
   - 🎁 **Подарок** → Открывается раздел подарков
   - 🤝 **Дружба** → Открывается раздел друзей

## 🚀 **Преимущества**

### **1. Улучшенный UX:**
- Пользователь сразу попадает в нужное место
- Не нужно искать нужный раздел
- Быстрый доступ к контенту

### **2. Повышенная вовлеченность:**
- Пользователи чаще реагируют на уведомления
- Уменьшается время до взаимодействия
- Увеличивается retention

### **3. Техническая надежность:**
- Задержка 500ms для стабильной навигации
- Обработка ошибок и fallback
- Совместимость с существующей навигацией

## 🔧 **Технические детали**

### **Структура данных уведомления:**
```typescript
{
  type: 'message' | 'stats_change' | 'gift' | 'friendship',
  action: 'open_chat' | 'open_profile' | 'open_gifts' | 'open_friends',
  deepLink: string, // ← Новое поле
  // ... другие поля
}
```

### **Обработка навигации:**
- **Задержка:** 500ms для завершения навигации
- **Метод:** `router.push(deepLink)`
- **Fallback:** Если deep link не работает, приложение откроется на главном экране

### **Совместимость:**
- Работает с существующей системой уведомлений
- Не ломает старые уведомления без deep links
- Поддерживает все типы уведомлений

Теперь push-уведомления ведут пользователя прямо к нужному месту! 🚀
