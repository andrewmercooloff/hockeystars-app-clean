# 🇺🇸 Настройка Twilio для отправки SMS в США

## ❌ Проблема

**Ошибка 21612**: Шведский номер Twilio (`+46731727922`) **не может** отправлять SMS на американские номера (`+1...`).

Это ограничение Twilio: номера из одной страны не могут отправлять SMS во все страны из-за регуляторных ограничений.

## ✅ Решение

Нужно купить **американский номер Twilio** для отправки SMS в США.

---

## 📋 Пошаговая инструкция

### 1. Купить американский номер в Twilio

1. Войдите в [Twilio Console](https://console.twilio.com)
2. Перейдите в **Phone Numbers** → **Manage** → **Buy a number**
3. Выберите страну: **United States**
4. Выберите тип номера:
   - **Toll-Free** (бесплатный для получателя) - рекомендуется для США
   - **Local** (локальный номер с кодом города)
5. Купите номер (стоимость ~$1-2/месяц)
6. Скопируйте номер телефона (например, `+12345678900`)

### 2. Настроить в app.json

Добавьте американский номер в конфигурацию:

```json
{
  "expo": {
    "extra": {
      "twilioAccountSid": "REDACTED_TWILIO_ACCOUNT_SID",
      "twilioAuthToken": "REDACTED_HEX_SECRET",
      "twilioFromNumber": "+46731727922",
      "twilioFromNumberUS": "+12345678900",
      "twilioWhatsAppFrom": "whatsapp:+14155238886"
    }
  }
}
```

**Где:**
- `twilioFromNumber` - шведский номер (для всех стран кроме США)
- `twilioFromNumberUS` - американский номер (для США)

### 3. Регистрация для A2P 10DLC (опционально, но рекомендуется)

Для отправки SMS в США через Twilio рекомендуется зарегистрировать кампанию A2P 10DLC:

1. В Twilio Console перейдите в **Messaging** → **Regulatory Compliance** → **A2P 10DLC**
2. Зарегистрируйте Brand (компанию)
3. Зарегистрируйте Campaign (кампанию)
4. Это улучшит доставляемость и снизит риск блокировки

**Важно:** Без регистрации A2P 10DLC могут быть ограничения на отправку.

---

## 🔧 Как это работает

Код автоматически определяет страну получателя по коду страны в номере:

- **+1...** (США) → использует `twilioFromNumberUS`
- **Все остальные** → использует `twilioFromNumber` (шведский)

---

## 💰 Стоимость

- **Американский номер**: ~$1-2/месяц
- **SMS в США**: ~$0.0075 за сообщение
- **Регистрация A2P 10DLC**: бесплатно (но может потребоваться верификация)

---

## ⚠️ Важные замечания

1. **Регуляторные требования**: США имеют строгие требования к SMS-маркетингу
2. **A2P 10DLC**: Рекомендуется для production использования
3. **Toll-Free номера**: Лучше подходят для отправки в США
4. **Ограничения**: Без регистрации могут быть ограничения на количество сообщений

## ✅ После настройки

После добавления `twilioFromNumberUS` в `app.json`:

1. Перезапустите приложение (`npx expo start -c`)
2. SMS на американские номера будут отправляться с американского номера
3. SMS на другие страны будут отправляться со шведского номера
