# Исправление прозрачности уведомлений

## 🐛 **Проблема**
Окошки уведомлений были слишком черными (непрозрачность 0.8), что делало их визуально тяжелыми и менее элегантными.

## ✅ **Решение**
Уменьшили непрозрачность фона уведомлений с 0.8 до 0.6, сделав их более прозрачными и элегантными.

## 🔧 **Технические изменения**

### **1. Основные элементы уведомлений:**

#### **До исправления:**
```typescript
backgroundColor: 'rgba(0, 0, 0, 0.8)', // Слишком темный
```

#### **После исправления:**
```typescript
backgroundColor: 'rgba(0, 0, 0, 0.6)', // Более прозрачный
```

### **2. Обновленные стили:**

#### **notificationItem:**
```typescript
// Было:
backgroundColor: 'rgba(0, 0, 0, 0.8)'

// Стало:
backgroundColor: 'rgba(0, 0, 0, 0.6)'
```

#### **emptyContent:**
```typescript
// Было:
backgroundColor: 'rgba(0, 0, 0, 0.8)'

// Стало:
backgroundColor: 'rgba(0, 0, 0, 0.6)'
```

#### **sectionHeader:**
```typescript
// Было:
backgroundColor: 'rgba(0, 0, 0, 0.8)'

// Стало:
backgroundColor: 'rgba(0, 0, 0, 0.6)'
```

#### **friendRequestItem:**
```typescript
// Было:
backgroundColor: 'rgba(0, 0, 0, 0.8)'

// Стало:
backgroundColor: 'rgba(0, 0, 0, 0.6)'
```

#### **header:**
```typescript
// Было:
backgroundColor: 'rgba(0, 0, 0, 0.8)'

// Стало:
backgroundColor: 'rgba(0, 0, 0, 0.6)'
```

## 🎯 **Результат**

### **До исправления:**
- **Непрозрачность:** 0.8 (80% черного)
- **Внешний вид:** Слишком темные, тяжелые контейнеры
- **Читаемость:** Хорошая, но визуально перегруженные

### **После исправления:**
- **Непрозрачность:** 0.6 (60% черного)
- **Внешний вид:** Более элегантные, легкие контейнеры
- **Читаемость:** Отличная, с лучшим визуальным балансом
