# Статус миграции с expo-av на expo-audio/expo-video

## 📋 Текущее состояние

### ✅ Выполнено:
1. Установлен пакет `expo-audio` (версия 1.0.14)
2. Изучен API `expo-audio` и выявлены ограничения

### ⚠️ Решение:
**Оставляем `expo-av` для всех функций до появления подходящего API**

### Причины:

1. **Воспроизведение звуков (`utils/soundService.ts`)**:
   - `expo-audio` использует hooks (`useAudioPlayer`), что не подходит для модульного кода
   - `expo-av` работает стабильно и подходит для модульного кода
   - Миграция потребует рефакторинга всего сервиса

2. **Запись аудио с метерингом (`app/puck-speed-sound.tsx`)**:
   - Используется сложная функциональность с метерингом
   - `expo-audio` может не поддерживать запись с метерингом или иметь другой API
   - Требуется дополнительное исследование

## 🔄 План на будущее:

1. **Дождаться стабильного API `expo-audio`** для модульного кода (без hooks)
2. **Или** дождаться, когда `expo-av` действительно будет удален (SDK 55+)
3. **Или** выполнить рефакторинг для использования hooks в компонентах

## 📝 Текущее использование expo-av:

- ✅ `utils/soundService.ts` - воспроизведение звуков (работает)
- ✅ `app/puck-speed-sound.tsx` - запись аудио с метерингом (работает)

## ⚠️ Важно:

- `expo-av` помечен как deprecated в SDK 54, но **все еще работает**
- Предупреждение в консоли не критично - приложение работает нормально
- Миграцию можно выполнить позже, когда будет более подходящий API

## 🎯 Рекомендация:

**Оставить `expo-av` как есть** до:
- Появления стабильного API `expo-audio` для модульного кода
- Или до момента, когда `expo-av` действительно перестанет работать
