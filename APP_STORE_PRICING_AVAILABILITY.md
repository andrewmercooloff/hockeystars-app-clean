# 💰 Ценообразование и доступность в App Store Connect

## ✅ Да, нужно заполнить, даже если приложение бесплатное!

Раздел **"Pricing and Availability"** (Ценообразование и доступность) **обязателен** для заполнения, даже если приложение бесплатное. Это один из обязательных разделов для публикации приложения.

---

## 📋 Что нужно заполнить для бесплатного приложения:

### 1. **Цена (Price)**
- ✅ Выберите: **"Free"** (Бесплатно)
- Это основная настройка цены

### 2. **Доступность (Availability)**
- ✅ **Выберите страны**, где приложение будет доступно
- Рекомендуется выбрать **"All countries"** (Все страны) для максимального охвата
- Или выберите конкретные страны, если есть ограничения

### 3. **Соглашение о ценах (Paid Applications Agreement)**
- ❌ **НЕ требуется** для бесплатных приложений
- Это соглашение нужно только для платных приложений

### 4. **Дополнительные настройки (опционально)**
- **Educational Discount**: скидка для образовательных учреждений (обычно не нужна для бесплатных)
- **Volume Purchase Program**: программа массовых покупок (обычно не нужна)

---

## 🎯 Пошаговая инструкция:

### Шаг 1: Откройте раздел "Pricing and Availability"
1. Войдите в [App Store Connect](https://appstoreconnect.apple.com/)
2. Выберите ваше приложение (App ID: 6753738837)
3. Перейдите в раздел **"Pricing and Availability"**

### Шаг 2: Установите цену
1. Найдите поле **"Price"**
2. Выберите **"Free"** из выпадающего списка
3. Нажмите **"Save"**

### Шаг 3: Настройте доступность
1. Найдите раздел **"Availability"**
2. Выберите один из вариантов:
   - ✅ **"All countries or regions"** (Рекомендуется) - приложение будет доступно во всех странах
   - Или **"Specific countries or regions"** - выберите конкретные страны
3. Нажмите **"Save"**

### Шаг 4: Проверьте настройки
- ✅ Цена: **Free**
- ✅ Доступность: **All countries** (или выбранные страны)
- ✅ Соглашение о ценах: **Не требуется** (для бесплатных)

---

## ⚠️ Важные моменты:

### 1. **Соглашение о ценах НЕ нужно**
- Для бесплатных приложений **не требуется** подписывать "Paid Applications Agreement"
- Это соглашение нужно только для платных приложений или приложений с in-app покупками

### 2. **Выбор стран**
- **Рекомендуется**: выбрать **"All countries"** для максимального охвата пользователей
- Если есть ограничения (например, языковые), можно выбрать конкретные страны
- Можно изменить список стран позже, без создания новой версии

### 3. **In-App Purchases (если есть)**
- Если в приложении есть **in-app покупки**, их нужно настроить отдельно
- Но основная цена приложения все равно может быть **Free**

---

## 📊 Пример заполнения для HockeyStars:

```
Price: Free

Paid Applications Agreement: Not required (бесплатное приложение)
Educational Discount: Not applicable
Volume Purchase Program: Not applicable
```

## 💡 Частые вопросы:

### Q: Нужно ли подписывать соглашение для бесплатного приложения?
**A:** Нет, для бесплатных приложений соглашение о ценах не требуется.

### Q: Можно ли изменить список стран позже?
**A:** Да, можно изменить доступность в любой момент, без создания новой версии.

### Q: Что если я хочу сделать приложение платным позже?
**A:** Можно изменить цену с "Free" на платную в любой момент, но тогда потребуется подписать "Paid Applications Agreement".

### Q: Нужно ли указывать цену для каждой страны отдельно?
**A:** Нет, для бесплатных приложений просто выберите "Free" - это применится ко всем странам.
