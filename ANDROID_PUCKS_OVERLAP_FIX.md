# Исправление наслаивания шайб и границ экрана на Android

## 🐛 **Проблема**
После финальной настройки:
- Шайбы наслаивались друг на друга на 5 пикселей
- Шайбы не долетали до краев экрана на 15 пикселей вниз и влево

## ✅ **Решение**
Точная настройка расстояния столкновений и границ экрана для идеального поведения.

## 🔧 **Технические изменения**

### **1. Минимальное расстояние столкновений:**
```typescript
// Было:
const minDistance = Platform.OS === 'android' ? puckSize * 0.4 : puckSize;

// Стало:
const minDistance = Platform.OS === 'android' ? puckSize * 0.5 : puckSize;
```
- **Увеличено** с 0.4 до 0.5 для Android
- **Результат:** Убрано наслаивание шайб друг на друга

### **2. Границы экрана:**
```typescript
// Было:
return {
  rightOffset: 180,  // Слишком много отступов
  bottomOffset: 430  // Слишком много отступов
};

// Стало:
return {
  rightOffset: 165,  // Уменьшено на 15px
  bottomOffset: 415  // Уменьшено на 15px
};
```
- **rightOffset:** 180 → 165 (-15px)
- **bottomOffset:** 430 → 415 (-15px)
- **Результат:** Шайбы долетают до краев экрана

## 🎯 **Результат**

### **До исправления:**
- Шайбы наслаивались друг на друга на 5px
- Шайбы не долетали до краев на 15px
- Неестественное поведение

### **После исправления:**
- Шайбы не наслаиваются друг на друга
- Шайбы долетают до краев экрана
- Идеальное поведение
