## Новая функция: `sendGiftNotification()`

### Что она делает:

1. **Создает in-app уведомление** в таблице `notifications`
2. **Увеличивает счетчик уведомлений** в поле `players.notifications`
3. **Отправляет push-уведомление** на все зарегистрированные устройства получателя
4. **Уведомляет друзей** о том, что игрок получил подарок

### Параметры:
```typescript
sendGiftNotification(
  playerId: string,          // ID получателя подарка
  playerName: string,        // Имя получателя
  senderName: string,        // Имя отправителя (Admin/Star name)
  giftName: string,          // Название подарка
  translations?: {           // Локализованные тексты
    giftReceived: string;
    giftReceivedMessage: string;
    giftReceivedPushTitle: string;
    giftReceivedPushBody: string;
  }
)
```

## Как тестировать

### 1. Тест: In-app уведомление и счетчик

1. **Войдите как звезда** (или админ)
2. **Откройте профиль игрока**
3. **Нажмите "Отправить подарок"**
4. **Выберите подарок и отправьте**
5. **Выйдите из звезды, войдите как игрок**
6. **Проверьте колокольчик снизу** - должен появиться красный индикатор с цифрой
7. **Откройте уведомления** - должно быть уведомление о подарке
8. **Подождите 3-5 секунд** - индикатор должен исчезнуть

### 2. Тест: Push-уведомление

⚠️ **Важно**: Push-уведомления приходят **только когда приложение в фоне или закрыто**

1. **Войдите как игрок на реальном устройстве** (не эмулятор)
2. **Убедитесь, что push-уведомления разрешены**
3. **Сверните приложение** (Home button / свайп вверх)
4. **Войдите как звезда на другом устройстве**
5. **Отправьте подарок игроку**
6. **На устройстве игрока должно появиться push-уведомление** с текстом:
   - 🎁 Подарок получен!
   - Вы получили подарок от [Star Name]: [Gift Name]

### 3. Тест: Локализация

1. **Смените язык на английский** (Settings)
2. **Повторите тест 1** - все тексты должны быть на английском:
   - "Gift Received!"
   - "You received a gift from Admin: [Gift Name]"
3. **Проверьте другие языки** (польский, немецкий, и т.д.)

### 4. Тест: Уведомления для друзей

1. **Создайте 2 аккаунта игроков**
2. **Добавьте их в друзья**
3. **Добавьте звезду в друзья к игроку 1** (если еще не сделано)
4. **Войдите как звезда**
5. **Отправьте подарок игроку 1**
6. **Проверьте у звезды** - НЕ должно быть уведомления (звезда сама отправила подарок)
7. **Войдите как игрок 2** (друг получателя)
8. **Проверьте уведомления** - должно быть уведомление:
   - "[Player 1 Name] получил подарок от [Star Name]: [Gift Name]"
9. **Индикатор на колокольчике** должен появиться у игрока 2

⚠️ **Важно**: Отправитель (звезда/админ) НЕ получает уведомление о подарке, который он сам отправил, даже если является другом получателя.

## Технические детали

### Таблицы БД:
- `notifications` - in-app уведомления
- `players` - поле `notifications` (счетчик)
- `push_tokens` - токены устройств для push

### Типы уведомлений:
- `gift_received` - основное уведомление для получателя
- `friend_gift_received` - уведомление для друзей

### Push Notification Handler:
Push-уведомления настроены через `Notifications.setNotificationHandler()` в `utils/notificationService.ts`:
- `shouldShowAlert: false` - не показывать когда приложение активно
- `shouldPlaySound: false` - не воспроизводить звук когда приложение активно
- `shouldSetBadge: true` - обновлять badge счетчик

---

## Известные ограничения

1. **Push только на реальных устройствах** - эмуляторы не поддерживают push-уведомления
2. **Push только в фоне** - когда приложение активно, показываются только in-app уведомления
3. **Требуется регистрация устройства** - пользователь должен войти в приложение хотя бы раз для регистрации push token

## Что делать при проблемах

### Не появляется индикатор на колокольчике:
1. Проверьте логи - есть ли `✅ Счетчик увеличен`?
2. Проверьте БД - есть ли запись в `notifications` с `is_read: false`?
3. Проверьте поле `players.notifications` - обновился ли `unread_count`?

### Не приходят push-уведомления:
1. Проверьте, что приложение в фоне (а не активно)
2. Проверьте, что устройство реальное (не эмулятор)
3. Проверьте логи - есть ли `✅ Push-уведомления отправлены`?
4. Проверьте таблицу `push_tokens` - есть ли зарегистрированные устройства?

### Неправильный язык:
1. Проверьте файл `locales/[lang].json` - есть ли ключи `gifts.giftReceived`, etc.?
2. Проверьте, что в AdminGiftModal/StarGiftModal используется `t('gifts.giftReceived')`
