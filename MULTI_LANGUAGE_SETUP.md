## 🚀 Быстрый старт

### 1. Экспорт таблицы переводов
```bash
node export_multi_language.js
```
Создает файл `multi_language_translation.csv` с 1979 ключами для перевода.

### 2. Перевод в Google Sheets
1. Откройте `multi_language_translation.csv` в Google Sheets
2. Используйте формулы Google Translate:
   - **Польский**: `=GOOGLETRANSLATE(B2,"ru","pl")`
   - **Шведский**: `=GOOGLETRANSLATE(B2,"ru","sv")`
   - **Чешский**: `=GOOGLETRANSLATE(B2,"ru","cs")`
   - **Словацкий**: `=GOOGLETRANSLATE(B2,"ru","sk")`
   - **Финский**: `=GOOGLETRANSLATE(B2,"ru","fi")`
   - **Итальянский**: `=GOOGLETRANSLATE(B2,"ru","it")`
   - **Немецкий**: `=GOOGLETRANSLATE(B2,"ru","de")`
   - **Французский**: `=GOOGLETRANSLATE(B2,"ru","fr")`
3. Скопируйте формулы для всех строк
4. Скопируйте и вставьте как значения (без формул)
5. Сохраните как CSV

### 3. Импорт перевода
```bash
node import_multi_language.js pl
```
Создает файл `locales/pl.json` с переводами.

### 4. Добавление поддержки языка в приложение
```bash
node add_language_support.js pl
```
Автоматически обновляет все необходимые файлы.
