# 🔒 Исправление критических проблем безопасности Supabase

## 📋 Проблемы из Security Advisor

Supabase обнаружил **11 критических проблем безопасности**:
- ❌ RLS отключен для таблиц: `item_requests`, `items`, `player_museum`, `teams`, `player_teams`
- ❌ Отсутствуют политики безопасности для некоторых таблиц
- ❌ Небезопасный доступ к Storage

## 🚀 Решение (3 шага)

### Шаг 1: Исправить RLS для основных таблиц

1. Откройте **Supabase Dashboard** → **SQL Editor**
2. Выполните файл: `database/fix_security_issues.sql`

```sql
-- Основные исправления:
-- ✅ Включить RLS для всех таблиц
-- ✅ Создать безопасные политики доступа
-- ✅ Ограничить права по ролям пользователей
```

### Шаг 2: Исправить Security для Storage

1. В том же **SQL Editor**
2. Выполните файл: `database/fix_storage_security.sql`

```sql
-- Storage исправления:
-- ✅ Безопасные политики для файлов
-- ✅ Лимиты размера файлов (10MB для аватаров)
-- ✅ Ограничение типов файлов (только изображения)
```

### Шаг 3: Проверить результат

1. Вернитесь в **Security Advisor**
2. Нажмите **Refresh** 🔄
3. Убедитесь что ошибки исчезли ✅

## 🔍 Что исправляется

### 🗄️ **Таблицы базы данных:**
- `item_requests` - запросы на предметы
- `items` - коллекционные предметы  
- `player_museum` - музей игрока
- `teams` - команды
- `player_teams` - связи игроков с командами

### 📁 **Storage (файлохранилище):**
- `avatars` - аватары пользователей
- `items` - изображения предметов

## 🛡️ Уровни безопасности

### 👤 **Обычные пользователи:**
- ✅ Могут читать публичные данные
- ✅ Могут изменять только свои данные
- ❌ Не могут изменять чужие данные

### 👑 **Администраторы:**
- ✅ Полный доступ к данным
- ✅ Могут управлять командами
- ✅ Могут удалять любые файлы

### 🔒 **Безопасность файлов:**
- ✅ Лимит 10MB для аватаров
- ✅ Лимит 50MB для предметов
- ✅ Только изображения (jpg, png, webp, gif, heic)
