# 📱 Инструкции для App Store ревьюеров

## 🔐 Универсальный секретный код для входа

Для тестирования приложения **HockeyStars** без получения SMS-кода используйте следующий универсальный секретный код:

### Секретный код: `291019`

---

## 📋 Пошаговая инструкция для входа:

### Шаг 1: Введите номер телефона
- Введите **любой номер телефона** в формате с кодом страны
- Например: `+1234567890` или `+79991234567`
- Нажмите "Отправить код" (Send Code)

### Шаг 2: Введите секретный код
- В поле "Код подтверждения" (Verification Code) введите: **`291019`**
- Нажмите "Подтвердить" (Verify)

### Шаг 3: Вход выполнен
- Приложение автоматически войдет в систему
- Секретный код работает для **любого номера телефона**

---

## ⚠️ Важные примечания:

1. **Секретный код универсальный** - работает для любого номера телефона
2. **Не нужно получать SMS** - секретный код заменяет SMS-код
3. **Код для тестирования** - предназначен только для ревьюеров App Store
4. **Секретный код:** `291019`

---

## 🔍 Альтернативный способ (для разработчиков):

Если номер телефона заканчивается на `######` (например: `+1234567890######`), то:
- SMS-подтверждение автоматически пропускается
- Можно использовать любой код (например: `123456`)

Но для ревьюеров **рекомендуется использовать универсальный секретный код** `291019` с любым номером телефона.

---

## 📝 Информация для App Store Connect:

При отправке приложения на ревью, в разделе **"App Review Information"** → **"Notes"** можно добавить:

```
Для входа в приложение используйте:
1. Любой номер телефона (например: +1234567890)
2. Секретный код: 291019

Этот код работает для любого номера телефона и не требует получения SMS.
```

---

## ✅ Проверка:

После ввода секретного кода `######`:
- ✅ Код должен быть принят
- ✅ Вход должен быть выполнен успешно
- ✅ Пользователь должен попасть в приложение

---

## 🆘 Если код не работает:

1. Убедитесь, что введен правильный код: **`291019`**
2. Проверьте, что номер телефона введен в правильном формате
3. Попробуйте перезапустить приложение

---
