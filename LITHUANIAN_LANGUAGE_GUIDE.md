# 🇱🇹 Литовский язык добавлен в HockeyStars!

## ✅ Что сделано

### 📱 **Полная поддержка литовского языка**
- **1,585+ переведенных ключей** на литовский язык
- **Автоматический перевод** всех UI элементов
- **Контекстные переводы** для хоккейной терминологии
- **Поддержка переменных** в переводах `{playerName}`, `{count}` и т.д.

### 🏒 **Специализированные переводы**

**Хоккейные позиции:**
- Крайний нападающий → `Krašto puolikas`
- Центральный нападающий → `Centro puolikas`
- Защитник → `Gynėjas`
- Вратарь → `Vartininkas`

**Статистика:**
- Голы → `Įvarčiai`
- Передачи → `Perdavimai`
- Подтягивания → `Atsitempimas`
- Отжимания → `Atsispaudimai`

**Упражнения:**
- Выносливость → `Ištvermė`
- Координация → `Koordinacija`
- Баланс → `Pusiausvyra`
- Восстановление → `Atsigavimas`

## 🚀 Как использовать

### 1. **В коде приложения**
Язык уже добавлен в `contexts/LanguageContext.tsx`:

```typescript
export type Language = 'ru' | 'lt' | 'en';

const translations = {
  ru: ruTranslations,
  en: enTranslations,
  lt: ltTranslations, // ← Литовский добавлен
};
```

### 2. **Переключение языка**
```typescript
const { setLanguage } = useLanguage();

// Переключить на литовский
setLanguage('lt');
```

### 3. **Примеры переводов**
```typescript
const { t } = useLanguage();

t('common.save')           // "Išsaugoti"
t('profile.player')        // "Žaidėjas" 
t('exercises.title')       // "Pratimai"
t('notifications.title')   // "Pranešimai"
```

### 🎯 **Особенности перевода:**

**Временные форматы:**
- `только что` → `ką tik`
- `{minutes} мин назад` → `{minutes} min. prieš`
- `{hours} ч назад` → `{hours} val. prieš`

**Подтверждения:**
- `Вы уверены?` → `Ar tikrai norite?`
- `Удалить фото?` → `ištrinti šią nuotrauką?`

**Страны и команды:**
- `Беларусь` → `Baltarusija`
- `Литва` → `Lietuva`
- `Сборная` → `Rinktinė`
