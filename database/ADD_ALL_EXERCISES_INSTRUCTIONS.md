## ✅ Что уже сделано:
1. **Навигация исправлена** - теперь при нажатии на упражнение открываются детали
2. **Создан SQL скрипт** - `add_all_exercises.sql` содержит все 65 упражнений с переводами
3. **Скрипт извлекает данные** из файлов локализации `locales/ru.json` и `locales/en.json`

## 📋 Что нужно сделать:

### Шаг 1: Очистить существующие упражнения (если нужно)
Если в базе данных уже есть упражнения 1-15, и вы хотите заменить их на полный набор:

```sql
-- Удалить существующие упражнения
DELETE FROM exercises;
```

### Шаг 2: Добавить все 65 упражнений
1. Откройте **Supabase Dashboard**
2. Перейдите в **SQL Editor**
3. Скопируйте содержимое файла `database/add_all_exercises.sql`
4. Вставьте в SQL Editor
5. Нажмите **Run**

### Шаг 3: Проверить результат
После выполнения скрипта выполните:

```sql
-- Проверить количество упражнений
SELECT COUNT(*) as total_exercises FROM exercises;

-- Посмотреть первые 5 упражнений
SELECT exercise_id, title_ru, title_en, category, difficulty 
FROM exercises 
ORDER BY exercise_id::int 
LIMIT 5;
```

## 🔧 Если возникнут ошибки:
1. **Ошибка дублирования**: Упражнения 1-15 уже существуют
   - Решение: Сначала удалите существующие упражнения (Шаг 1)
   
2. **Ошибка синтаксиса**: Проблема с кавычками в SQL
   - Решение: Проверьте, что скрипт скопирован полностью

3. **Ошибка прав доступа**: Нет прав на запись в таблицу
   - Решение: Убедитесь, что вы вошли в Supabase как владелец проекта
