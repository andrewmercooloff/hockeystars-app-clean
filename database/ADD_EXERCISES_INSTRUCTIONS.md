# Добавление дополнительных упражнений в базу данных

## ❌ Проблема:
При попытке выполнить `add_all_exercises.sql` возникает ошибка:
```
ERROR: 23505: duplicate key value violates unique constraint "exercises_exercise_id_key"
DETAIL: Key (exercise_id)=(1) already exists.
```

Это означает, что упражнения 1-15 уже существуют в базе данных.

## ✅ Решения:

### Вариант 1: Добавить только дополнительные упражнения (16-20)
**Рекомендуется для начала**

1. Откройте **Supabase Dashboard**
2. Перейдите в **SQL Editor**
3. Скопируйте содержимое файла `database/add_more_exercises.sql`
4. Вставьте в SQL Editor
5. Нажмите **Run**

**Результат:** Будет добавлено 5 новых упражнений (16-20), всего станет 20 упражнений.

### Вариант 2: Заменить все упражнения на полный набор (65)
**Если хотите все 65 упражнений**

1. Сначала выполните:
```sql
-- Удалить все существующие упражнения
DELETE FROM exercises;
```

2. Затем выполните содержимое `database/add_all_exercises.sql`

**Результат:** Будет 65 упражнений с полными переводами.

### Вариант 3: Проверить существующие упражнения
**Сначала посмотрите, что у вас есть**

1. Выполните содержимое `database/check_existing_exercises.sql`
2. Посмотрите, сколько упражнений уже есть
3. Выберите подходящий вариант выше

## 📊 Ожидаемый результат после Варианта 1:
- **20 упражнений** в базе данных (15 существующих + 5 новых)
- **Новые категории**: Сила, Ловкость, Растяжка
- **Новые уровни сложности**: Начинающий, Продвинутый
- **Рабочая навигация** ко всем упражнениям

## 🔧 Если возникнут ошибки:
1. **Ошибка дублирования**: Упражнение с таким ID уже существует
   - Решение: Используйте Вариант 1 (добавить только новые)

2. **Ошибка синтаксиса**: Проблема с кавычками в SQL
   - Решение: Проверьте, что скрипт скопирован полностью

3. **Ошибка прав доступа**: Нет прав на запись в таблицу
   - Решение: Убедитесь, что вы вошли в Supabase как владелец проекта

6. Проверьте фильтрацию по новым категориям
