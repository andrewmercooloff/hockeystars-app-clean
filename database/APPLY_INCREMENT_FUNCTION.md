# Применение SQL функций для счетчика уведомлений

## 📝 Что делать:

1. **Откройте Supabase Dashboard** → https://supabase.com/dashboard
2. **Выберите ваш проект** → `hockeystars-app-clean`
3. **Перейдите в SQL Editor** (левое меню)
4. **Скопируйте и вставьте** содержимое файла `create_increment_function.sql`
5. **Нажмите "Run"**

## ✅ Что это делает:

- Создает функцию `increment_unread_notifications(user_id)` - увеличивает счетчик на 1
- Создает функцию `reset_unread_notifications(user_id)` - обнуляет счетчик

## 🎯 Зачем это нужно:

Упрощает логику обновления счетчика уведомлений:
- Вместо сложного чтения → парсинга JSON → обновления
- Теперь просто: вызов одной функции!

## ⚠️ Важно:

Выполните этот скрипт **ПЕРЕД** тестированием новых уведомлений!
