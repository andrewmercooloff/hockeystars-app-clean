# Быстрое решение: Восстановление всех 65 упражнений

## ❌ Проблема:
У вас сейчас только 5 упражнений (16-20) вместо всех 65.

## ✅ Решение:

### Вариант 1: Использовать существующий файл (РЕКОМЕНДУЕТСЯ)
1. Откройте **Supabase Dashboard**
2. Перейдите в **SQL Editor**
3. Скопируйте **ВСЕ** содержимое файла `database/add_all_exercises.sql`
4. Вставьте в SQL Editor
5. Нажмите **Run**

**Результат:** Все 65 упражнений будут добавлены в базу данных.

### Вариант 2: Пошаговое добавление
Если файл `add_all_exercises.sql` слишком большой, выполните:

1. **Сначала удалите все упражнения:**
```sql
DELETE FROM exercises;
```

2. **Затем добавьте упражнения по частям:**
   - Скопируйте первые 20 упражнений из `add_all_exercises.sql`
   - Выполните в SQL Editor
   - Повторите для следующих 20 упражнений
   - И так далее

### Вариант 3: Проверить, что у вас есть
Сначала выполните:
```sql
SELECT COUNT(*) as total_exercises FROM exercises;
SELECT exercise_id, title_ru FROM exercises ORDER BY exercise_id::int;
```

## 📊 Ожидаемый результат:
- **65 упражнений** в базе данных
- **Все категории** и уровни сложности
- **Полные переводы** на русский и английский
- **Рабочая навигация** ко всем упражнениям

## 🔧 Если возникнут ошибки:
1. **Ошибка дублирования**: Упражнения уже существуют
   - Решение: Сначала выполните `DELETE FROM exercises;`

2. **Ошибка синтаксиса**: Проблема с кавычками
   - Решение: Проверьте, что скрипт скопирован полностью

3. **Файл слишком большой**: Не помещается в SQL Editor
   - Решение: Разделите на части по 20 упражнений

## 📱 После выполнения:
1. Перезапустите приложение
2. Перейдите в раздел "Упражнения"
3. Должно отображаться 65 упражнений
4. Проверьте навигацию к деталям
5. Проверьте фильтрацию по категориям
