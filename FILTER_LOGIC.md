# Логика подсчета количества пользователей в фильтрах

## Общая информация

На главном экране (`app/index.tsx`) используется система фильтрации игроков с двумя фильтрами:
- **CountryFilter** - фильтр по странам
- **YearFilter** - фильтр по годам рождения

## Логика фильтрации на главном экране

### Исходные данные

1. **Все игроки** (`players`) - загружаются из базы данных
2. **Скрытые игроки** - игроки с `is_hidden = true` **всегда исключаются** из главного экрана
3. **Заблокированные пользователи** - исключаются из отображения на льду

### Процесс фильтрации

#### Шаг 1: Исключение скрытых игроков
```typescript
const visiblePlayersForHome = players.filter(player => !player.is_hidden);
```
- **Все скрытые игроки** (`is_hidden = true`) исключаются
- Это применяется **ко всем пользователям**, включая админов
- Админы могут видеть скрытые профили в поиске, но **не на главном экране**

#### Шаг 2: Применение фильтров через `getSmartPlayerSelection`
```typescript
const selected = getSmartPlayerSelection(
  visiblePlayersForHome, // Уже без скрытых
  currentUser?.id,
  currentUser?.status,
  effectiveCountry,  // undefined если "Все"
  effectiveYear,     // undefined если "Все"
  randomSeed
);
```

**Параметры фильтрации:**
- `effectiveCountry` - выбранная страна или `undefined` (если выбрано "Все")
- `effectiveYear` - выбранный год или `undefined` (если выбрано "Все")
- `currentUser?.id` - ID текущего пользователя (для умного выбора)
- `currentUser?.status` - статус пользователя (player/coach/star)
- `randomSeed` - случайное число для рандомизации

#### Шаг 3: Исключение заблокированных пользователей
```typescript
if (blockedUsers.length > 0) {
  const blockedSet = new Set(blockedUsers);
  filtered = filtered.filter(player => !blockedSet.has(player.id));
}
```

### Результат: `allVisiblePlayers`

Итоговый список игроков, которые отображаются на главном экране:
- ✅ Не скрытые (`!is_hidden`)
- ✅ Соответствуют выбранным фильтрам (страна/год)
- ✅ Не заблокированы текущим пользователем
- ✅ Выбраны через `getSmartPlayerSelection` (умный выбор с учетом статуса пользователя)

## CountryFilter - Логика подсчета

### Какие игроки учитываются в фильтре стран:

1. **Исключаются:**
   - Скрытые игроки (`is_hidden = true`)
   - Игроки без указанной страны (`country === null/undefined`)

2. **Учитываются:**
   - Все игроки со статусом `player` (игроки)
   - Игроки со статусом `coach` (тренеры)
   - Игроки со статусом `star` (звёзды)

### Подсчет для опции "Все":
```
Всего видимых игроков = players.filter(p => !p.is_hidden && p.status === 'player').length
```

### Подсчет для конкретной страны:
```
Игроков в стране X = players.filter(p => 
  !p.is_hidden && 
  p.country === 'X' && 
  p.status === 'player'
).length
```

**Важно:** В фильтре стран учитываются только игроки со статусом `player`, но в списке стран могут быть представлены все страны, где есть любые пользователи (включая тренеров и звёзд).

## YearFilter - Логика подсчета

### Какие игроки учитываются в фильтре годов:

1. **Исключаются:**
   - Скрытые игроки (`is_hidden = true`)
   - Игроки без даты рождения (`birthDate === null/undefined`)
   - Звёзды (`status === 'star'`)

2. **Учитываются:**
   - Игроки со статусом `player` (по дате рождения)
   - Тренеры (`status === 'coach'`) - их годы берутся из `coach_years` массива

3. **Ограничение по стране:**
   - Если выбрана страна в `CountryFilter`, то подсчет ведется только для игроков этой страны
   - Если страна не выбрана ("Все"), то подсчет ведется для всех игроков

### Подсчет для опции "Все":
```typescript
// Если выбрана страна:
visiblePlayers = players.filter(p => 
  p.country === selectedCountry && 
  !p.is_hidden && 
  p.status === 'player'
).length

// Если страна не выбрана:
visiblePlayers = players.filter(p => 
  !p.is_hidden && 
  p.status === 'player'
).length
```

### Подсчет для конкретного года:
```typescript
// Базовый список игроков (с учетом выбранной страны)
const scopedPlayers = selectedCountry
  ? players.filter(p => p.country === selectedCountry && !p.is_hidden)
  : players.filter(p => !p.is_hidden);

// Подсчет игроков по году рождения
scopedPlayers.forEach(player => {
  if (player.status === 'player' && player.birthDate) {
    const birthYear = extractYear(player.birthDate);
    if (birthYear) {
      yearCounts[birthYear]++;
    }
  }
  
  // Для тренеров - добавляем их coach_years
  if (player.status === 'coach' && player.coach_years) {
    player.coach_years.forEach(year => {
      if (!yearCounts[year]) {
        yearCounts[year] = 0; // Год доступен, но игроков может не быть
      }
    });
  }
});
```

**Важно:** 
- Годы тренеров (`coach_years`) добавляются в список доступных годов, даже если нет игроков с таким годом рождения
- Если тренер имеет `coach_years = [2005, 2006]`, то эти годы появятся в фильтре, даже если нет игроков 2005 или 2006 года рождения

## Взаимодействие фильтров

### При выборе страны:
1. Если выбрана страна → `YearFilter` автоматически ограничивается игроками этой страны
2. Если выбрана страна, но в этой стране нет игроков выбранного года → год сбрасывается на "Все"

### При выборе года:
1. Если выбран год → `CountryFilter` автоматически сбрасывается на "Все"
2. Это позволяет показывать игроков выбранного года из всех стран

### При выборе "Все" в любом фильтре:
- Другой фильтр также сбрасывается на "Все"
- Показываются все видимые игроки без ограничений

## Максимальное количество игроков на экране

**Максимум: 25 игроков**

Максимальное количество игроков, которые могут отображаться на главном экране одновременно, ограничено константой `MAX_PLAYERS = 25` в функции `getSmartPlayerSelection`.

Это ограничение применяется **независимо от выбранных фильтров**:
- ✅ Страна = "Все" → максимум 25 игроков
- ✅ Страна = "BY" → максимум 25 игроков
- ✅ Год = 2005 → максимум 25 игроков
- ✅ Страна = "BY" + Год = 2005 → максимум 25 игроков

### Логика отбора игроков (приоритеты)

Игроки отбираются в следующем порядке приоритета (до 30 человек):

1. **Администраторы** - всегда показываются первыми
2. **Текущий пользователь** - если он игрок, всегда показывается
3. **Новички** - до 5 игроков, зарегистрировавшихся в последние 5 дней
4. **Топ-5 игроков** - по рейтингу активности (исключая новичков)
5. **Остальные не-игроки** - магазины, заточка коньков (если проходят фильтры)
6. **Тренеры** - до 5 тренеров (все при фильтре по году, или рандомные при "Все года")
7. **Звёзды и скауты** - до 5 человек (до 3 звёзд + до 2 скаутов)
8. **Случайные игроки** - заполняют все оставшиеся места до 25 (если постоянных игроков 15, то случайных будет 10; если постоянных 20, то случайных будет 5)

**Важно:** Если постоянных игроков (категории 1-7) больше 25, они обрезаются до 25 с сохранением приоритета. Случайные игроки заполняют только оставшиеся места.

**Обновление случайных игроков:**
- При встряхивании телефона (shake gesture) обновляется `randomSeed`, что приводит к появлению новых случайных игроков
- Shake детектируется через акселерометр (expo-sensors)
- Минимальный интервал между shake: 2 секунды
- При shake происходит вибрация для обратной связи

## Итоговое количество отображаемых игроков

На главном экране отображается количество игроков из `allVisiblePlayers`, которое:
- ✅ Исключает скрытых (`!is_hidden`)
- ✅ Применяет фильтры страны и года
- ✅ Исключает заблокированных пользователей
- ✅ Использует умный выбор через `getSmartPlayerSelection` (учитывает статус пользователя, рандомизацию и т.д.)
- ✅ **Ограничено максимумом в 25 игроков**

**Формула:**
```
Отображаемые игроки = getSmartPlayerSelection(
  players.filter(p => !p.is_hidden),
  currentUser?.id,
  currentUser?.status,
  selectedCountry || undefined,
  selectedYear || undefined,
  randomSeed
).filter(p => !blockedUsers.includes(p.id))

// getSmartPlayerSelection возвращает максимум 25 игроков
```

## Примеры

### Пример 1: Все фильтры = "Все"
- Всего игроков в БД: 1000
- Скрытых: 50
- Заблокированных: 10
- **Отображается:** максимум **25 игроков** (выбираются по приоритету из ~940 видимых)

### Пример 2: Страна = "BY", Год = "Все"
- Всего игроков в БД: 1000
- Игроков из BY: 200
- Скрытых из BY: 10
- **Отображается:** максимум **25 игроков** из BY (выбираются по приоритету из ~190 видимых)

### Пример 3: Страна = "Все", Год = 2005
- Всего игроков в БД: 1000
- Игроков 2005 года: 50
- Скрытых 2005 года: 5
- **Отображается:** максимум **25 игроков** 2005 года из всех стран (выбираются по приоритету из ~45 видимых)

### Пример 4: Страна = "BY", Год = 2005
- Всего игроков в БД: 1000
- Игроков из BY 2005 года: 10
- Скрытых из BY 2005 года: 1
- **Отображается:** **9 игроков** из BY 2005 года (меньше максимума, так как всего 9 видимых)

### Пример 5: Очень узкий фильтр
- Страна = "BY", Год = 2010
- Игроков из BY 2010 года: 3
- Скрытых: 0
- **Отображается:** **3 игрока** (меньше максимума, так как всего 3 соответствуют фильтру)

### Пример 6: Очень широкий фильтр
- Страна = "Все", Год = "Все"
- Всего видимых игроков: 5000
- **Отображается:** **25 игроков** (максимум, выбираются по приоритету: админы → текущий пользователь → новички → топ-5 → случайные)

### Пример 7: Обновление через shake
- Пользователь встряхивает телефон
- Обновляется `randomSeed` (новое значение на основе текущего времени)
- **Результат:** Появляются новые случайные игроки (до 10 человек), заменяя предыдущих случайных
- Постоянные игроки (админы, текущий пользователь, новички, топ-5, тренеры, звёзды) остаются без изменений
