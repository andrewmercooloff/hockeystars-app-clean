# Исправление позиции аватара в хедере

## 🎯 **Цель**
Сдвинуть аватар с именем в хедере на 5 пикселей вправо для улучшения визуального баланса.

## ✅ **Решение**
Уменьшили `marginRight` аватара с 76.5px до 71.5px, что сдвинуло его на 5px вправо.

## 🔧 **Технические изменения**

### **Компонент LogoHeader:**

#### **До исправления:**
```typescript
<TouchableOpacity 
  style={{ 
    alignItems: 'center', 
    marginRight: 76.5, // Отступ справа 76.5px
    minHeight: 70, 
    marginBottom: -6 
  }}
>
```

#### **После исправления:**
```typescript
<TouchableOpacity 
  style={{ 
    alignItems: 'center', 
    marginRight: 71.5, // Отступ справа 71.5px (сдвиг на 5px вправо)
    minHeight: 70, 
    marginBottom: -6 
  }}
>
```

## 🎯 **Результат**

### **До исправления:**
- **marginRight:** 76.5px
- **Позиция:** Аватар дальше от правого края
- **Визуальный баланс:** Менее сбалансированный

### **После исправления:**
- **marginRight:** 71.5px
- **Позиция:** Аватар на 5px ближе к правому краю
- **Визуальный баланс:** Более сбалансированный

## 🔧 **Технические детали**

### **Изменение позиции:**
- **Было:** `marginRight: 76.5px`
- **Стало:** `marginRight: 71.5px`
- **Сдвиг:** +5px вправо (уменьшение marginRight на 5px)

### **Структура хедера:**
```typescript
<View style={{ 
  height: 128, 
  flexDirection: 'row',
  justifyContent: 'space-between',
  alignItems: 'flex-end',
  paddingBottom: 5,
  backgroundColor: '#000'
}}>
  {/* Логотип слева */}
  <View style={{ marginLeft: 61.5, marginBottom: -5 }}>
    <Image source={logo} style={{ width: 189, height: 63 }} />
  </View>
  
  {/* Аватар справа */}
  <TouchableOpacity style={{ 
    alignItems: 'center', 
    marginRight: 71.5, // Обновленное значение
    minHeight: 70, 
    marginBottom: -6 
  }}>
    {/* Аватар и имя */}
  </TouchableOpacity>
</View>
```

### **Сохраненные свойства:**
- **alignItems:** 'center' - центрирование по горизонтали
- **minHeight:** 70 - минимальная высота
- **marginBottom:** -6 - отступ снизу
- **Функциональность:** Остается без изменений
