# Инструкция по использованию Development Build

## Первая установка (один раз, долго)

### Шаг 1: Включите режим разработчика на iPhone
1. Откройте **Настройки** → **Конфиденциальность и безопасность**
2. Прокрутите вниз до раздела **Режим разработчика**
3. Включите переключатель **Режим разработчика**
4. Перезагрузите iPhone (если потребуется)

**Альтернативный путь:**
- **Настройки** → **Основные** → **VPN и управление устройством** → **Режим разработчика**

### Шаг 2: Установите приложение
1. Установите приложение на iPhone через ссылку или QR-код
2. После установки откройте **Настройки** → **Основные** → **VPN и управление устройством**
3. Найдите профиль разработчика (обычно "Expo" или "EAS Build")
4. Нажмите **Доверять** и подтвердите

### Шаг 3: Запустите приложение
- Приложение будет называться "HockeyStars" с иконкой Expo Dev Client

## Ежедневное использование (быстро, без пересборки)

### Шаг 1: Запустите dev server
```bash
npx expo start --dev-client
```

### Шаг 2: Откройте приложение на iPhone
- Приложение автоматически подключится к dev server
- Или отсканируйте QR-код из терминала

### Шаг 3: Смотрите логи в реальном времени
Все `console.log`, `console.error`, `console.warn` будут видны в терминале!

## Преимущества Development Build:
✅ **Быстрые обновления** - изменения кода применяются мгновенно (hot reload)  
✅ **Логи в реальном времени** - все console.log видны в терминале  
✅ **Отладка** - можно использовать React Native Debugger  
✅ **Без пересборки** - после первого раза не нужно ждать 20 минут  

## Если нужно обновить нативные модули:
Если вы добавили новый нативный модуль (например, новую библиотеку), нужно пересобрать:
```bash
eas build --platform ios --profile development
```

## Просмотр логов:
- Все логи видны в терминале где запущен `expo start --dev-client`
- Можно фильтровать: `npx expo start --dev-client | grep "iOS"`
- Для более детальной отладки используйте React Native Debugger
