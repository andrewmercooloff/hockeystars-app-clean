## 🚫 Проблема с правами доступа

### Диагностика:
- Ошибка: `new row violates row-level security policy for table "exercises"`
- Анонимный пользователь не может обновлять таблицу `exercises`
- RLS политики блокируют операции UPDATE и INSERT

### Возможные решения:

#### Вариант 1: Отключить RLS для таблицы exercises
```sql
ALTER TABLE exercises DISABLE ROW LEVEL SECURITY;
```

#### Вариант 2: Создать политику для обновления
```sql
CREATE POLICY "Allow anonymous updates to exercises" ON exercises
FOR UPDATE USING (true);
```

#### Вариант 3: Использовать service role key
- Получить service role key из Supabase Dashboard
- Использовать его для обновления данных

#### Вариант 4: Обновить через Supabase Dashboard
- Войти в Supabase Dashboard
- Открыть таблицу exercises
- Обновить данные вручную
