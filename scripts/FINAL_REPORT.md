## 🚀 КАК ПРИМЕНИТЬ ИСПРАВЛЕНИЯ

### Вариант 1: SQL скрипт (РЕКОМЕНДУЕТСЯ)
1. Откройте **Supabase Dashboard**
2. Перейдите в **SQL Editor**
3. Скопируйте содержимое файла **`update-exercises.sql`**
4. Выполните SQL скрипт
5. Проверьте результат

### Вариант 2: Ручное обновление
1. Откройте файл **`manual-update-exercises.csv`**
2. Для каждого упражнения выполните SQL команды из колонок "SQL Update Instructions" и "SQL Update Tips"

### Вариант 3: Отключить RLS (если нужно)
Если возникают проблемы с правами доступа, выполните:
```sql
ALTER TABLE exercises DISABLE ROW LEVEL SECURITY;
```

## 🌍 ПЕРЕВОД НА ДРУГИЕ ЯЗЫКИ

### Шаг 1: Подготовка
1. Откройте **`exercises-translation-template.csv`** в Google Sheets
2. Формулы `GOOGLETRANSLATE` автоматически переведут текст с русского на английский

### Шаг 2: Перевод
1. Скопируйте переведенные колонки
2. Вставьте в новый файл
3. Проверьте качество перевода
4. При необходимости отредактируйте

### Шаг 3: Загрузка в базу
1. Обновите соответствующие колонки в таблице `exercises` (например, `instructions_en`, `tips_en`)
2. Повторите для всех языков

## 📋 ПРИМЕРЫ ИСПРАВЛЕННЫХ УПРАЖНЕНИЙ

### Упражнение #38 "Прыжки с поворотами"

**БЫЛО:**
- Инструкции: `[]` (пусто)
- Советы: `[]` (пусто)

**СТАЛО:**
- **Инструкции:**
  1. Встаньте прямо, ноги на ширине плеч
  2. Сделайте прыжок вверх
  3. Во время прыжка повернитесь на 180 градусов
  4. Приземлитесь мягко на обе ноги
  5. Сразу повернитесь обратно и повторите

- **Советы:**
  1. Приземляйтесь на полусогнутые ноги
  2. Работайте руками для баланса
  3. Начинайте с небольших поворотов
  4. Следите за техникой приземления
