# Deep Links для уведомлений

## 🎯 **Цель**
Настроить правильную навигацию для всех типов уведомлений, чтобы они вели в соответствующие разделы приложения.

## ✅ **Решение**
Добавлены deep links для всех типов уведомлений с правильной навигацией в соответствующие разделы.

## 🔧 **Технические изменения**

### **1. Обновлена функция `handleNotificationPress`:**

#### **Статистика (stats_change):**

## 🔧 **Технические детали**

### **Типы уведомлений и их deep links:**

#### **Профиль игрока:**
- `friend_request` → `/player/{playerId}`
- `friend_accepted` → `/player/{acceptorId}`
- `autograph_request` → `/player/{playerId}`
- `stick_request` → `/player/{playerId}`
- `avatar_changed` → `/player/{playerId}`
- `new_friendship` → `/player/{confirmedBy}`

#### **Статистика:**
- `stats_change` → `/player/{playerId}?scrollToStats=true`
- `physical_data_changed` → `/player/{playerId}?scrollToStats=true`

#### **Фото:**
- `photo_added` → `/player/{playerId}?scrollToPhotos=true`

#### **Видео:**
- `video_added` → `/player/{playerId}?scrollToVideos=true`

#### **Достижения:**
- `achievement_added` → `/player/{playerId}?scrollToAchievements=true`
- `achievement` → `/player/{playerId}?scrollToAchievements=true`

#### **Упражнения:**
- `exercise_completed` → `/exercise/{exerciseId}` или `/player/{playerId}?scrollToExercises=true`

#### **Музей:**
- `gift_accepted` → `/player/{currentUserId}?scrollToMuseum=true`
- `gift_received` → `/player/{playerId}?scrollToMuseum=true`

#### **Команды:**
- `team_invite` → `/teams`

#### **Системные:**
- `system` → остаемся в разделе уведомлений

### **Параметры прокрутки:**
- `scrollToStats=true` - прокрутка к статистике
- `scrollToPhotos=true` - прокрутка к фото
- `scrollToVideos=true` - прокрутка к видео
- `scrollToAchievements=true` - прокрутка к достижениям
- `scrollToExercises=true` - прокрутка к упражнениям
- `scrollToMuseum=true` - прокрутка к музею
