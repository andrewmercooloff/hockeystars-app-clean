# Диагностика push-уведомлений для сообщений

## 🔍 **Проблема**
Push-уведомления для новых сообщений не приходят, хотя сообщения отправляются успешно.

## 📊 **Анализ логов**
Из логов видно:
```
📨 ОТПРАВКА СООБЩЕНИЯ: {"receiverId": "3cd6dfc5-699b-4770-90cb-572edd39a9f3", "senderId": "1bc22582-30bf-4375-9c0b-ac6132542094", "text": "Тест..."}
📱 Push-уведомления будут отправлены через Realtime подписку
```

Но нет логов:
- `💬 Новое сообщение получено через Realtime:`
- `📱 PUSH: Отправляем уведомление о сообщении`

## 🔧 **Внесенные исправления**

### 1. **Добавлено логирование в RealtimeManager:**
```typescript
console.log('🔧 Настраиваем подписку на сообщения для пользователя:', userId);
console.log('✅ Подписка на сообщения создана для пользователя:', userId);
```

### 2. **Улучшено логирование в setupMessagesSubscription:**
```typescript
console.log('💬 Отправитель:', payload.new.sender_id);
console.log('💬 Получатель:', payload.new.receiver_id);
console.log('💬 Текст:', payload.new.text);
```

## 🧪 **План диагностики**

### Шаг 1: Проверка push-токенов
```sql
-- Запустите в Supabase SQL Editor
\i check_message_push_tokens.sql
```

### Шаг 2: Проверка логов
После отправки сообщения должны появиться логи:
- `🔧 Настраиваем подписку на сообщения для пользователя:`
- `✅ Подписка на сообщения создана для пользователя:`
- `💬 Новое сообщение получено через Realtime:`

### Шаг 3: Возможные причины

#### A. **Нет push-токенов у получателя**
- Проверить таблицу `push_tokens`
- Убедиться, что токены зарегистрированы

#### B. **Realtime подписка не работает**
- Проверить подключение к Supabase
- Убедиться, что подписка создается

#### C. **Фильтр подписки не срабатывает**
- Проверить, что `receiver_id` совпадает с `userId`

#### D. **Expo Go ограничения**
- Push-уведомления могут не работать в Expo Go
- Нужен development build для полного тестирования

## 🚀 **Следующие шаги**

1. **Отправьте сообщение** и проверьте логи
2. **Запустите SQL скрипт** для проверки токенов
3. **Если логи не появляются** - проблема в Realtime подписке
4. **Если логи есть, но push не приходит** - проблема в Expo Go

Теперь диагностика должна быть более точной! 🔍
