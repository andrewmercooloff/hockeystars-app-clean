# Исправления UI проблем на Android

## 🐛 **Проблемы**

### 1. **Шайбы отталкиваются слишком далеко**
- Шайбы отталкивались друг от друга на расстояние в 2 раза больше их размера
- Шайбы залетали за правый и нижний край экрана на ~50 пикселей

### 2. **Двойная вложенность в сообщениях**
- В разделе сообщений элементы чатов имели двойную вложенность контейнеров
- На Android это создавало визуальное различие с iOS

## ✅ **Исправления**

### 1. **Исправление коллизий шайб на Android**

#### **Уменьшено минимальное расстояние между шайбами:**
```typescript
// app/index.tsx
// Было:
const minDistance = puckSize;

// Стало:
const minDistance = Platform.OS === 'android' ? puckSize * 0.8 : puckSize;
```

#### **Скорректированы границы экрана для Android:**
```typescript
// app/index.tsx
// Было:
rightOffset: 165,  // Шайбы залетали за правый край
bottomOffset: 425  // Шайбы залетали за нижний край

// Стало:
rightOffset: 115,  // Уменьшено на 50px
bottomOffset: 375  // Уменьшено на 50px
```

### 2. **Исправление вложенности в сообщениях**

#### **Убрана двойная вложенность для Android:**
```typescript
// app/messages.tsx
chatItem: {
  // ...
  backgroundColor: Platform.OS === 'android' ? 'rgba(0, 0, 0, 0.8)' : 'rgba(0, 0, 0, 0.7)',
  borderWidth: Platform.OS === 'android' ? 0 : 1,  // Убираем границу на Android
  // ...
}
```

#### **Добавлен импорт Platform:**
```typescript
import {
    Alert,
    Image,
    ImageBackground,
    Platform,  // Добавлен импорт
    RefreshControl,
    // ...
} from 'react-native';
```

### **Сообщения:**
