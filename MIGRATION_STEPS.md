# 🚀 Инструкция по миграции упражнений

## ✅ Что уже готово:

1. **Таблица `exercises` создана** в Supabase
2. **15 упражнений** готовы к миграции (1-15)
3. **Приложение обновлено** для работы с базой данных
4. **SQL скрипт исправлен** и готов к выполнению

## 📋 Шаги для завершения миграции:

### 1. Выполните SQL скрипт в Supabase Dashboard

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите проект `hockeystars-app`
3. Перейдите в **SQL Editor**
4. Скопируйте содержимое файла `database/add_exercises_11_15.sql`
5. Вставьте в SQL Editor и нажмите **Run**

### 2. Проверьте результат

Выполните этот запрос для проверки:
```sql
SELECT 
  exercise_id, 
  title_ru, 
  title_en, 
  category, 
  difficulty,
  is_active
FROM exercises 
ORDER BY exercise_id::integer;
```

Должно быть **15 упражнений** (10 уже существующих + 5 новых).

### 3. Протестируйте приложение

1. Запустите приложение: `npx expo start`
2. Перейдите в раздел **Упражнения**
3. Убедитесь, что упражнения загружаются из базы данных
4. Проверьте переключение языков

## 🎯 Ожидаемый результат:

- ✅ **15 упражнений** отображаются в приложении
- ✅ **Переводы работают** на русском и английском
- ✅ **Фильтрация по категориям** работает
- ✅ **Загрузка из базы данных** работает

## 🔧 Если что-то не работает:

1. **Проверьте подключение к Supabase** - выполните тест:
   ```bash
   node test_exercises_db.js
   ```

2. **Проверьте логи приложения** - смотрите консоль на ошибки

3. **Убедитесь, что таблица создана** - проверьте в Supabase Dashboard
