# 🔧 Исправление системы годов для тренеров

## ❌ Проблема:
Поле `coach_years` не существует в базе данных, поэтому кнопки годов не работают.

## ✅ Решение:

### 1️⃣ Добавьте поле в базу данных

Выполните этот SQL в **Supabase Dashboard** → **SQL Editor**:

```sql
-- Добавляем поле для годов тренера
ALTER TABLE public.players ADD COLUMN coach_years INTEGER[];

-- Создаем индекс для быстрого поиска
CREATE INDEX IF NOT EXISTS idx_players_coach_years ON public.players USING GIN (coach_years);

-- Добавляем комментарий
COMMENT ON COLUMN public.players.coach_years IS 'Годы рождения игроков, которых тренирует этот тренер (только для status=coach)';
```

### 2️⃣ Перезапустите приложение

```bash
npx expo start --clear
```

### 3️⃣ Проверьте работу

1. Войдите в профиль тренера
2. Нажмите "Редактировать"
3. Найдите секцию "Тренирует годы"
4. Выберите годы - они должны подсвечиваться **красным**
5. Сохраните изменения

## 🔍 Отладка:

Если кнопки годов все еще не работают, проверьте терминал на наличие логов:
- `🔍 Player data coach_years: ...` - показывает загруженные данные
- `✅ Set coach years: ...` - подтверждает установку годов
- `❌ No coach_years found or not array` - означает что поле не загружается
