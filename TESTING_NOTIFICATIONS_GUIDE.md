# Руководство по тестированию уведомлений

## 🔍 **Анализ текущей ситуации**

Из логов видно, что система работает правильно, но уведомления блокируются кешем:

```
⏭️ Пропускаем дублирующееся push-уведомление (глобальный кеш)
```

## ✅ **Внесенные исправления**

### 1. **Уменьшено время кеширования:**
- **Основной кеш**: 5 минут → 1 минута
- **Push кеш**: 5 минут → 1 минута  
- **NotificationService кеш**: 10 секунд → 5 секунд

### 2. **Созданы скрипты для диагностики:**
- `check_push_tokens.sql` - проверка push токенов
- `clear_notification_cache.js` - очистка кеша

## 🧪 **План тестирования**

### Шаг 1: Проверка push токенов
```sql
-- Запустите в Supabase SQL Editor
\i check_push_tokens.sql
```

### Шаг 2: Очистка кеша (если нужно)
```javascript
// Запустите в консоли браузера или в приложении
\i clear_notification_cache.js
```

### Шаг 3: Тестирование
1. **Откройте приложение на Android** (Expo Go)
2. **Откройте приложение на iOS** (Expo Go) 
3. **Войдите под разными пользователями**
4. **Добавьте друг друга в друзья**
5. **Подождите 1-2 минуты** (чтобы кеш очистился)
6. **Измените статистику** одного пользователя
7. **Проверьте уведомления** на другом устройстве

## ⚠️ **Важные замечания**

### Push-уведомления в Expo Go:
- **Expo Go** имеет ограничения для push-уведомлений
- **Полное тестирование** возможно только в TestFlight или development build
- **In-app уведомления** должны работать в любом случае

### Проверка in-app уведомлений:
1. Откройте экран **"Уведомления"** в приложении
2. Проверьте, появились ли новые уведомления
3. Проверьте счетчик уведомлений

## 📊 **Ожидаемые результаты**

### После исправлений:
- ✅ **Уведомления должны приходить** через 1-2 минуты после изменения
- ✅ **In-app уведомления** должны работать в Expo Go
- ✅ **Push-уведомления** могут не работать в Expo Go (это нормально)
- ✅ **Счетчик уведомлений** должен обновляться

### Логи для отслеживания:
- `📢 Отправлено X уведомлений о статистике` - уведомления созданы
- `✅ Уведомления отправлены на X/Y устройств` - push отправлены
- `⏭️ Пропускаем дублирующееся push-уведомление` - кеш работает

## 🚀 **Следующие шаги**

1. **Протестируйте** с новыми настройками кеша
2. **Проверьте in-app уведомления** в Expo Go
3. **Для полного тестирования push** - используйте TestFlight
4. **Мониторьте логи** на наличие ошибок

Если уведомления все еще не приходят, возможно проблема в push-токенах или настройках Expo Go.
