### 1. Иконка приложения (КРИТИЧНО!)

### 2. Скриншоты для App Store (ОБЯЗАТЕЛЬНО!)
- [ ] **iPhone 6.7"** (1290 x 2796 px) - минимум 1, рекомендуется 3-10
- [ ] **iPhone 6.5"** (1242 x 2688 px) - опционально
- [ ] **iPhone 5.5"** (1242 x 2208 px) - опционально
- [ ] **iPad** (если поддерживается):
  - iPad Pro 12.9" (2048 x 2732 px)
  - iPad Pro 11" (1668 x 2388 px)

**Как сделать скриншоты:**
1. Запустите приложение на реальном устройстве или симуляторе
2. Сделайте скриншоты ключевых экранов
3. Обрежьте до нужных размеров
4. Или используйте инструменты: [App Store Screenshot Generator](https://www.appstorescreenshot.com/)

### 3. Privacy Policy (КРИТИЧНО! Без этого отклонят!)
- [ ] Создать Privacy Policy на сайте или отдельной странице
- [ ] URL должен быть доступен публично (HTTPS)
- [ ] Должна описывать:
  - Какие данные собираются (если собираются)
  - Как используются данные
  - Использование push-уведомлений
  - Использование микрофона и камеры
  - Использование аналитики (если есть)
  - Права пользователей
- [ ] Privacy Policy на всех языках приложения (русский, английский, и т.д.)

**Пример структуры Privacy Policy:**
```
1. Введение
2. Какие данные мы собираем
   - Данные аккаунта (email, имя)
   - Данные устройства (для push-уведомлений)
   - Использование микрофона (только для измерения скорости шайбы)
   - Использование камеры (только для измерения скорости шайбы)
3. Как мы используем данные
4. Передача данных третьим лицам (Supabase, Expo, и т.д.)
5. Безопасность данных
6. Права пользователей
7. Изменения в Privacy Policy
8. Контакты
```

## 📋 Пошаговый план действий

### Шаг 1: Подготовка контента (1-2 дня)
1. Проверить/создать иконку 1024x1024
2. Сделать скриншоты для App Store
3. Написать Privacy Policy и разместить на сайте
4. Подготовить описание приложения
5. Подготовить ключевые слова

### Шаг 2: Настройка в App Store Connect (1 день)
1. Войти в [App Store Connect](https://appstoreconnect.apple.com/)
2. Открыть приложение (App ID: 6753738837)
3. Заполнить всю информацию:
   - App Information
   - Pricing and Availability
   - App Privacy (важно!)
   - App Store Information (описание, скриншоты, иконка)
   - Version Information

### Шаг 3: Создание и загрузка build (1 день)
1. Создать production build:
   ```bash
   eas build --platform ios --profile production
   ```
2. Дождаться завершения (обычно 15-30 минут)
3. Загрузить в App Store Connect:
   ```bash
   eas submit --platform ios --profile production
   ```

### Шаг 4: Отправка на ревью (30 минут)
1. В App Store Connect выбрать build
2. Заполнить "What's New in This Version"
3. Добавить примечания для ревьюеров (если нужно)
4. Нажать "Submit for Review"

### Шаг 5: Ожидание ревью (1-3 дня)
- Обычно занимает 24-48 часов
- Может быть отклонено с комментариями
- После одобрения автоматически публикуется
