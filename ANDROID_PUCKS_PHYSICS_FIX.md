# Исправление физики шайб на Android

## 🐛 **Проблема**
На Android шайбы отталкивались друг от друга слишком далеко и вылетали за правую и нижнюю границы экрана.

## ✅ **Решение**
Исправлены настройки физики столкновений и границы экрана для Android.

## 🔧 **Технические изменения**

### **1. Минимальное расстояние между шайбами:**
```typescript
// Было:
const minDistance = Platform.OS === 'android' ? puckSize * 0.8 : puckSize;

// Стало:
const minDistance = Platform.OS === 'android' ? puckSize * 1.1 : puckSize;
```
- **Увеличено** с 0.8 до 1.1 для Android
- **Результат:** Шайбы не подходят слишком близко друг к другу

### **2. Сила отталкивания при столкновениях:**
```typescript
// Было:
const pushForce = overlap * (Platform.OS === 'ios' ? 0.6 : (Platform.OS === 'android' ? 0.15 : 0.18));

// Стало:
const pushForce = overlap * (Platform.OS === 'ios' ? 0.6 : (Platform.OS === 'android' ? 0.4 : 0.18));
```
- **Увеличено** с 0.15 до 0.4 для Android
- **Результат:** Более контролируемое отталкивание

### **3. Границы экрана:**
```typescript
// Было:
return {
  leftOffset: 5,
  topOffset: 5,
  rightOffset: 115,  // Слишком мало
  bottomOffset: 375  // Слишком мало
};

// Стало:
return {
  leftOffset: 5,
  topOffset: 5,
  rightOffset: 150,  // Увеличено на 35px
  bottomOffset: 400  // Увеличено на 25px
};
```
- **rightOffset:** 115 → 150 (+35px)
- **bottomOffset:** 375 → 400 (+25px)
- **Результат:** Шайбы не вылетают за границы

### **4. Сила толчка при перетаскивании:**
```typescript
// Было:
const pushStrength = Platform.OS === 'ios' ? 0.8 : 0.2;

// Стало:
const pushStrength = Platform.OS === 'ios' ? 0.8 : (Platform.OS === 'android' ? 0.5 : 0.2);
```
- **Увеличено** с 0.2 до 0.5 для Android
- **Результат:** Более естественное поведение при перетаскивании

## 🎯 **Результат**

### **До исправления:**
- Шайбы отталкивались слишком далеко
- Вылетали за правую границу (115px)
- Вылетали за нижнюю границу (375px)
- Слабое отталкивание (0.15)
- Слабый толчок при перетаскивании (0.2)

### **После исправления:**
- Контролируемое отталкивание
- Остаются в пределах экрана
- Увеличенные границы (150px справа, 400px снизу)
- Усиленное отталкивание (0.4)
- Усиленный толчок при перетаскивании (0.5)

## 🧪 **Тестирование**

### **Сценарий 1: Столкновения шайб**
1. **Откройте главный экран** с несколькими шайбами
2. **Подождите** пока шайбы столкнутся
3. **Проверьте** - шайбы должны отталкиваться умеренно
4. **Проверьте** - шайбы не должны вылетать за границы

### **Сценарий 2: Перетаскивание шайбы**
1. **Перетащите шайбу** к другой шайбе
2. **Проверьте** - шайбы должны толкать друг друга естественно
3. **Проверьте** - перетаскиваемая шайба не должна вылетать за границы

### **Ожидаемый результат:**
- Шайбы остаются в пределах экрана
- Естественное отталкивание
- Плавные столкновения
- Контролируемое поведение

## 🔧 **Технические детали**

### **Физика столкновений:**
- **minDistance:** 1.1 * puckSize (было 0.8)
- **pushForce:** 0.4 * overlap (было 0.15)
- **pushStrength:** 0.5 при перетаскивании (было 0.2)

### **Границы экрана:**
- **rightOffset:** 150px (было 115px)
- **bottomOffset:** 400px (было 375px)
- **leftOffset:** 5px (без изменений)
- **topOffset:** 5px (без изменений)

### **Совместимость:**
- Изменения только для Android
- iOS и Web остаются без изменений
- Обратная совместимость сохранена
