# Исправление вложенных контейнеров в разделе сообщений

## 🐛 **Проблема**
В разделе сообщений чаты отображались как прямоугольник одного цвета внутри контейнера с скругленными краями другого цвета, создавая эффект вложенных контейнеров. В уведомлениях все выглядело нормально.

## ✅ **Решение**
Убрали платформо-специфичные различия в стилях чатов, сделав единообразный дизайн для всех платформ.

## 🔧 **Технические изменения**

### **Стиль chatItem:**

#### **До исправления:**
```typescript
chatItem: {
  flexDirection: 'row',
  alignItems: 'center',
  paddingHorizontal: 20,
  paddingVertical: 16,
  backgroundColor: Platform.OS === 'android' ? 'rgba(0, 0, 0, 0.8)' : 'rgba(0, 0, 0, 0.7)',
  marginHorizontal: 16,
  marginVertical: 6,
  borderRadius: 12,
  borderWidth: Platform.OS === 'android' ? 0 : 1, // Проблема!
  borderColor: 'rgba(250, 47, 64, 0.3)', // Проблема!
  shadowColor: '#000',
  shadowOffset: { width: 0, height: 2 },
  shadowOpacity: 0.25,
  shadowRadius: 3.84,
  elevation: 5,
},
```

#### **После исправления:**
```typescript
chatItem: {
  flexDirection: 'row',
  alignItems: 'center',
  paddingHorizontal: 20,
  paddingVertical: 16,
  backgroundColor: 'rgba(0, 0, 0, 0.7)', // Единый цвет для всех платформ
  marginHorizontal: 16,
  marginVertical: 6,
  borderRadius: 12,
  // Убрали borderWidth и borderColor - они создавали эффект вложенных контейнеров
  shadowColor: '#000',
  shadowOffset: { width: 0, height: 2 },
  shadowOpacity: 0.25,
  shadowRadius: 3.84,
  elevation: 5,
},
```

## 🎯 **Результат**

### **До исправления:**
- **Android:** Темный прямоугольник (rgba(0, 0, 0, 0.8)) без границ
- **iOS:** Светлый прямоугольник (rgba(0, 0, 0, 0.7)) с красной границей
- **Проблема:** Разный внешний вид, эффект вложенных контейнеров на iOS

### **После исправления:**
- **Android:** Единый дизайн без границ
- **iOS:** Единый дизайн без границ
- **Результат:** Одинаковый внешний вид на всех платформах

## 🔧 **Технические детали**

### **Удаленные свойства:**
- **borderWidth:** Убрано платформо-специфичное условие
- **borderColor:** Убрано полностью
- **Причина:** Создавали эффект вложенных контейнеров

### **Унифицированные свойства:**
- **backgroundColor:** 'rgba(0, 0, 0, 0.7)' для всех платформ
- **borderRadius:** 12px для всех платформ
- **marginHorizontal:** 16px для всех платформ
- **marginVertical:** 6px для всех платформ

### **Сохраненные свойства:**
- **shadowColor, shadowOffset, shadowOpacity, shadowRadius** - для объемности
- **elevation** - для Android теней
- **paddingHorizontal, paddingVertical** - для внутренних отступов
