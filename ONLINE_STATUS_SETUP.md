# 🌐 Инструкция по настройке онлайн-офлайн статуса

## 📋 Что нужно сделать

Система онлайн-офлайн статуса полностью готова в коде, но нужно применить SQL изменения к базе данных Supabase.

## 🚀 Шаги для применения изменений

### 1. Откройте Supabase Dashboard
- Перейдите на https://supabase.com/dashboard
- Войдите в свой аккаунт
- Выберите проект `hockeystars-app`

### 2. Откройте SQL Editor
- В левом меню найдите "SQL Editor"
- Нажмите "New query" для создания нового запроса

### 3. Скопируйте и выполните SQL скрипт
Скопируйте содержимое файла `database/add_online_status_fields.sql` и вставьте в SQL Editor.

### 4. Выполните команды
Нажмите кнопку "Run" для выполнения всех SQL команд.

## 📄 Что делает скрипт

Скрипт добавляет два новых поля в таблицу `players`:

1. **`is_online`** (BOOLEAN) - Статус онлайн пользователя
   - `true` = пользователь онлайн
   - `false` = пользователь офлайн
   - По умолчанию: `false`

2. **`last_seen`** (TIMESTAMP) - Время последней активности
   - Автоматически обновляется при активности пользователя
   - По умолчанию: текущее время (NOW())

## ✅ Проверка результата

После выполнения скрипта выполните следующий запрос для проверки:

```sql
SELECT 
  id, 
  name, 
  is_online, 
  last_seen 
FROM players 
LIMIT 10;
```

Должны увидеть поля `is_online` и `last_seen` для всех пользователей.

## 🔄 Что дальше?

После применения миграции:
1. Перезапустите приложение
2. При входе пользователя статус `is_online` будет автоматически обновляться
3. В чате и на шайбах будет отображаться статус онлайн/офлайн
4. Красная точка на шайбах будет показываться для онлайн пользователей

## 📝 Примечания

- Индексы созданы для быстрого поиска онлайн пользователей
- Все существующие пользователи получат `is_online = false` и `last_seen = NOW()`
- Статус будет автоматически обновляться при входе/выходе пользователя
