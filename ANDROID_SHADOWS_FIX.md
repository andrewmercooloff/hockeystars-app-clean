# Исправление теней шайб для Android

## 🐛 **Проблема**
На Android тени от шайб отображались плоско внизу, в то время как на iPhone тени были объемными вокруг шайбы, как и должно быть.

## ✅ **Решение**
Добавлены платформо-специфичные стили теней для Android, которые создают объемный эффект, аналогичный iOS.

## 🔧 **Технические изменения**

### **1. Основные тени шайб (puck и starPuck):**

#### **До исправления:**
```typescript
android: {
  elevation: 8, // Только плоская тень внизу
},
```

#### **После исправления:**
```typescript
android: {
  elevation: 12, // Увеличена высота тени
  shadowColor: '#000', // Добавлен цвет тени
  shadowOffset: {
    width: 0,
    height: 4, // Смещение тени
  },
  shadowOpacity: 0.6, // Прозрачность тени
  shadowRadius: 6, // Радиус размытия тени
},
```

### **2. Тени аватаров:**

#### **До исправления:**
```typescript
android: {
  elevation: 3, // Только плоская тень
},
```

#### **После исправления:**
```typescript
android: {
  elevation: 6, // Увеличена высота тени
  shadowColor: '#000', // Добавлен цвет тени
  shadowOffset: {
    width: 0,
    height: 2, // Смещение тени
  },
  shadowOpacity: 0.4, // Прозрачность тени
  shadowRadius: 3, // Радиус размытия тени
},
```

### **3. Тени на льду (iceShadow):**

#### **До исправления:**
```typescript
android: {
  elevation: 4, // Только плоская тень
},
```

#### **После исправления:**
```typescript
android: {
  elevation: 6, // Увеличена высота тени
  shadowColor: '#000', // Добавлен цвет тени
  shadowOffset: {
    width: 0,
    height: 2, // Смещение тени
  },
  shadowOpacity: 0.5, // Прозрачность тени
  shadowRadius: 3, // Радиус размытия тени
},
```

## 🎯 **Результат**

### **До исправления:**
- **Android:** Плоские тени только внизу
- **iOS:** Объемные тени вокруг шайб
- **Различие:** Разный визуальный эффект на платформах

### **После исправления:**
- **Android:** Объемные тени вокруг шайб (как на iOS)
- **iOS:** Объемные тени вокруг шайб (без изменений)
- **Единообразие:** Одинаковый визуальный эффект на всех платформах

3. **Проверьте** - тени должны быть объемными
4. **Проверьте** - тени должны быть более выраженными
