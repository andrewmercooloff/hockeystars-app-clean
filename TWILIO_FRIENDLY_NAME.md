# 📞 Friendly Name в Twilio

## ⚠️ Важно: Friendly Name НЕ отображается получателям!

**Friendly Name** в Twilio Console - это только для **внутреннего управления** номерами. Получатели SMS/звонков **не увидят** это имя.

---

## 🔧 Настройка Friendly Name (для внутреннего использования)

### В Twilio Console:

1. Перейди в **Phone Numbers** → **Manage** → **Active numbers**
2. Выбери свой номер (`+46731727922`)
3. В поле **Friendly Name** введи имя (например: `HockeyStars SMS`)
4. Нажми **Save**

**Это поможет тебе:**
- ✅ Легче находить номера в консоли
- ✅ Организовывать номера по назначению
- ✅ Понимать, какой номер для чего используется

**Но получатели НЕ увидят это имя!**

---

## 📱 Что видят получатели

### Для SMS:
- **Всегда показывается номер**: `+46731727922`
- Friendly name **не работает** для SMS
- Нет способа изменить отображаемое имя в SMS

### Для голосовых вызовов:
- **По умолчанию**: показывается номер `+46731727922`
- **Для США**: можно использовать **CNAM** (Caller ID Name), но:
  - ✅ Только для американских номеров
  - ✅ Требует EIN (Employer Identification Number) или DUNS
  - ✅ Работает не на всех операторах
  - ✅ Максимум 15 символов

---

## 💡 Альтернативы для отображения имени

### 1. В тексте SMS (рекомендуется)

Вместо того, чтобы полагаться на Friendly name, просто **включи имя в текст сообщения**:

```typescript
// В utils/smsService.ts
const message = `HockeyStars: Your verification code is ${code}`;
// или
const message = `[HockeyStars] Your code: ${code}`;
```

**Преимущества:**
- ✅ Работает везде
- ✅ Не требует настройки
- ✅ Пользователь сразу видит, от кого сообщение

### 2. CNAM для голосовых вызовов (только США)

Если у тебя есть американский номер и EIN/DUNS:

1. В Twilio Console → **Phone Numbers** → выбери номер
2. Перейди в **Caller ID Name**
3. Введи имя (до 15 символов): `HockeyStars`
4. Сохрани

**Ограничения:**
- ❌ Только для США
- ❌ Требует EIN/DUNS
- ❌ Работает не на всех операторах

## 🎯 Рекомендация для твоего приложения

### Для SMS:
**Используй имя в тексте сообщения:**

```typescript
// В utils/smsService.ts, строка 75
const message = `HockeyStars code: ${code}`;
// или более явно:
const message = `HockeyStars verification code: ${code}. Do not share this code.`;
```

### Для голосовых вызовов:
**Используй имя в TwiML:**

```xml
<Say voice="alice" language="en-US">
    Hello, this is HockeyStars. Your verification code is: 1, 2, 3, 4, 5, 6.
</Say>
```
