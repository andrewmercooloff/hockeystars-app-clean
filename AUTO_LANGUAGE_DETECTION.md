# 🌍 Автоматическое определение языка устройства

## ✅ Что реализовано

### 1. **Автоматическое определение языка при первом запуске**
- Приложение теперь автоматически определяет язык устройства при первом запуске
- Если язык устройства поддерживается приложением, он устанавливается автоматически
- Если язык не поддерживается, устанавливается английский по умолчанию

### 2. **Поддерживаемые языки**
- 🇷🇺 Русский (ru)
- 🇺🇸 Английский (en) 
- 🇱🇹 Литовский (lt)
- 🇱🇻 Латышский (lv)
- 🇵🇱 Польский (pl)
- 🇸🇪 Шведский (sv)
- 🇨🇿 Чешский (cs)
- 🇸🇰 Словацкий (sk)
- 🇫🇮 Финский (fi)
- 🇮🇹 Итальянский (it)
- 🇩🇪 Немецкий (de)
- 🇫🇷 Французский (fr)

### 3. **Новая опция "Автоматически" в переключателе языков**
- Добавлена опция "Автоматически" в меню выбора языка
- Позволяет сбросить язык на автоматическое определение устройства
- Визуально выделена иконкой глобуса и кнопкой обновления

## 🚀 Как это работает

### При первом запуске приложения:
1. Проверяется, есть ли сохраненный язык в AsyncStorage
2. Если есть - используется сохраненный язык
3. Если нет - определяется язык устройства через `Localization.locale`
4. Если язык устройства поддерживается - устанавливается автоматически
5. Если не поддерживается - устанавливается английский
6. Определенный язык сохраняется в AsyncStorage

### При выборе "Автоматически":
1. Определяется текущий язык устройства
2. Устанавливается этот язык
3. Сохраняется в AsyncStorage для будущих запусков

## 📱 Примеры работы

### Сценарий 1: Пользователь из России
- Устройство: `ru-RU`
- Результат: Автоматически устанавливается русский язык

### Сценарий 2: Пользователь из Литвы  
- Устройство: `lt-LT`
- Результат: Автоматически устанавливается литовский язык

### Сценарий 3: Пользователь из Японии
- Устройство: `ja-JP` (не поддерживается)
- Результат: Устанавливается английский язык

### Сценарий 4: Пользователь сменил язык устройства
- Пользователь выбирает "Автоматически" в настройках
- Приложение определяет новый язык устройства
- Устанавливается новый язык

## 🎯 Преимущества

1. **Улучшенный UX** - пользователи сразу видят приложение на своем языке
2. **Автоматическая адаптация** - приложение подстраивается под настройки устройства
3. **Fallback на английский** - гарантирует, что приложение всегда будет понятно
4. **Возможность сброса** - пользователь может вернуться к автоматическому режиму
5. **Сохранение выбора** - пользовательские настройки сохраняются между запусками
