# Обновление дизайна кнопки удаления сообщения свайпом

## 🎨 **Изменение дизайна**
Обновлен дизайн кнопки удаления сообщения при свайпе - убран красный квадрат, оставлена только красная корзина меньшего размера.

## 🔄 **До и После**

### **Было:**
- Красный квадрат с белой корзиной
- Размер корзины: 32px
- Цвет корзины: белый (#fff)
- Фон: красный (#fa2f40)

### **Стало:**
- Прозрачный фон с красной корзиной
- Размер корзины: 24px (уменьшен)
- Цвет корзины: красный (#fa2f40)
- Фон: прозрачный (transparent)

## 🔧 **Технические изменения**

### **1. Изменение иконки:**
```typescript
// Было:
<Ionicons name="trash-outline" size={32} color="#fff" />

// Стало:
<Ionicons name="trash-outline" size={24} color="#fa2f40" />
```

### **2. Изменение стиля:**
```typescript
// Было:
deleteButton: {
  backgroundColor: '#fa2f40',
  justifyContent: 'center',
  alignItems: 'center',
  width: 60,
  height: '100%',
},

// Стало:
deleteButton: {
  backgroundColor: 'transparent',
  justifyContent: 'center',
  alignItems: 'center',
  width: 60,
  height: '100%',
},
```

## 🎯 **Преимущества нового дизайна**

### **1. Более чистый вид:**
- Убран лишний красный фон
- Корзина выглядит более элегантно
- Меньше визуального шума

### **2. Лучшая читаемость:**
- Красная корзина на прозрачном фоне
- Четкое понимание действия
- Соответствует общему стилю приложения

### **3. Уменьшенный размер:**
- Корзина 24px вместо 32px
- Более пропорциональный размер
- Не занимает слишком много места

## 🧪 **Тестирование**

### **Сценарий:**
1. **Откройте чат** с сообщениями
2. **Сделайте свайп** влево на любом сообщении
3. **Проверьте** - должна появиться красная корзина без фона
4. **Нажмите на корзину** - сообщение должно удалиться

### **Ожидаемый результат:**
- Красная корзина размером 24px
- Прозрачный фон
- Плавная анимация свайпа
- Корректное удаление сообщения

## 🎨 **Визуальные характеристики**

### **Цветовая схема:**
- **Корзина:** #fa2f40 (красный)
- **Фон:** transparent (прозрачный)
- **Размер:** 24px

### **Позиционирование:**
- **Ширина:** 60px
- **Высота:** 100% (на всю высоту сообщения)
- **Выравнивание:** по центру

### **Анимация:**
- Плавный свайп влево
- Появление корзины справа
- Возврат при отпускании
