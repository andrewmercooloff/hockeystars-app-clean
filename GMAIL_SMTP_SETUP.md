# 📧 Настройка Gmail SMTP для HockeyStars

## 🔐 Создание App Password

1. **Войдите в Google Account**
   - https://myaccount.google.com/

2. **Безопасность → Двухфакторная аутентификация**
   - Включите двухфакторную аутентификацию

3. **Создание App Password**
   - Перейдите в "Приложения с паролем"
   - Выберите "Другое" 
   - Назовите "HockeyStars App"
   - Скопируйте сгенерированный 16-значный пароль

## ⚠️ ВАЖНО:
- Никогда не храните пароль в коде
- Используйте переменные окружения
- Периодически меняйте App Password

## 🚨 Безопасность:
- App Password действует только для одного приложения
- Может быть в любой момент отозван
- Не требует полного доступа к аккаунту

## 📧 Настройки SMTP:
- **SMTP Сервер**: smtp.gmail.com
- **Порт**: 587 (TLS)
- **Логин**: hockeystars.by@gmail.com
- **Пароль**: Сгенерированный App Password
