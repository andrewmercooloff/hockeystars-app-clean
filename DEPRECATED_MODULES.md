# Deprecated модули - что это значит и что делать

## Что означает "deprecated"?

**Deprecated** = модуль больше не поддерживается разработчиками, но **пока еще работает**.

### Уровни критичности:

1. **Низкая критичность (можно игнорировать сейчас):**
   - Модуль работает, но не получает обновлений
   - Используется только как транзитивная зависимость (установлен другими пакетами)
   - Примеры: `inflight`, `glob@7.x`, `rimraf@3.x`

2. **Средняя критичность (нужно планировать замену):**
   - Модуль используется напрямую в вашем коде
   - Есть альтернативы
   - Пример: `react-native-audio-recorder-player` → заменить на `react-native-nitro-sound`

3. **Высокая критичность (нужно заменить срочно):**
   - Модуль имеет известные уязвимости безопасности
   - Может перестать работать в новых версиях React Native/Expo
   - Примеры: старые версии `xmldom` с уязвимостями
