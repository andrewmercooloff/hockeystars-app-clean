================================================================================
  Переключение api.hockey-stars.com обратно на Supabase Custom Domain
  (вместо Node.js прокси на BY cPanel 178.172.217.60)
================================================================================

Почему BY «10 минут работало, потом перестало»:
  - Shared hosting Node.js (Passenger) засыпает / падает по памяти → 503
  - SSL на LiteSpeed иногда «догоняет» после рестарта
  - Custom Domain (CNAME → supabase.co) стабильнее на мобильном LTE в РФ

--------------------------------------------------------------------------------
ШАГ 1 — cPanel HostFly (hockey-stars.com)
--------------------------------------------------------------------------------
1. Setup Node.js App → найти приложение для api / api.hockey-stars.com
2. Stop Application (или Delete — прокси больше не нужен)
3. Убедиться, что порт/процесс не слушает api

--------------------------------------------------------------------------------
ШАГ 2 — DNS (панель HostFly, зона hockey-stars.com)
--------------------------------------------------------------------------------
УДАЛИТЬ:
  A    api    →  178.172.217.60

ДОБАВИТЬ:
  CNAME  api  →  jvsypfwiajuwsyuzkyda.supabase.co

Если Supabase Dashboard просит TXT для SSL:
  TXT  _acme-challenge.api  →  (значение из Dashboard → Custom Domains)

TTL: 300–600 сек (быстрее проверка). Подождать 5–30 мин.

Проверка с ПК (PowerShell):
  nslookup api.hockey-stars.com
  → должен быть CNAME на jvsypfwiajuwsyuzkyda.supabase.co (не 178.172.217.60)

--------------------------------------------------------------------------------
ШАГ 3 — Supabase Dashboard
--------------------------------------------------------------------------------
Project → Settings → Custom Domains
  → api.hockey-stars.com → Activate / Verify (если был deactivated)

Статус: Active + SSL issued

--------------------------------------------------------------------------------
ШАГ 4 — Тест БЕЗ VPN (телефон, мобильный интернет)
--------------------------------------------------------------------------------
Открыть в браузере:
  https://api.hockey-stars.com/rest/v1/

Ожидание: JSON с кодом 401 и сообщением про apikey — это УСПЕХ.
Не открывается / timeout → DNS ещё не обновился или Custom Domain не active.

Скрипт с ПК:
  .\deploy\scripts\test-supabase-proxy.ps1

--------------------------------------------------------------------------------
ШАГ 5 — Приложение
--------------------------------------------------------------------------------
1. Полностью закрыть HockeyStars (смахнуть из недавних)
2. Открыть снова (подтянет OTA если есть связь с u.expo.dev)
3. EXPO_PUBLIC_SUPABASE_URL уже = https://api.hockey-stars.com (eas.json)

Если после смены DNS что-то «липнет» к старому прокси:
  — в коде есть resetSupabaseEndpointPreference() / сброс при полном fail fetch
  — переустановка приложения = крайний случай

OTA (нужен VPN если Expo блокируется):
  cd c:\hockeystars-app-clean-old-recovered
  npx eas update --branch production --message "Custom domain + clear sticky origin on fail"

Store build (если OTA не доходит без VPN):
  npx eas build --platform android --profile production

--------------------------------------------------------------------------------
Что НЕ трогать
--------------------------------------------------------------------------------
  hockey-stars.com (сайт) — A на BY как был
  u.expo.dev — OTA отдельно; в РФ иногда только с VPN
