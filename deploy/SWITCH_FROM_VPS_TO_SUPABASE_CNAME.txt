  ОТКАЗ ОТ VPS-ПРОКСИ → Supabase Custom Domain (рекомендуется)
================================================================================

ПРОБЛЕМА VPS (5.42.123.84):
  Телефон → VPS Москва → supabase.co = ДВА звена + Nginx + SSL + keepalive
  Любой сбой на прокси = пустой экран, 502, «Пользователь» вместо имён.
  Retries на клиенте и nginx УМНОЖАЮТ задержку (до 90 секунд на один запрос).

РЕКОМЕНДУЕМОЕ РЕШЕНИЕ:
  Supabase Custom Domain — DNS CNAME напрямую на supabase.co.
  Supabase сам выдаёт SSL и маршрутизирует через Cloudflare.
  В РФ обходит блокировку *.supabase.co на мобильных операторах.

  Путь: Телефон → api.hockey-stars.com (CNAME) → Supabase CDN → база
  (одно звено меньше, без своего Nginx)

--------------------------------------------------------------------------------
ШАГ 1 — DNS (панель HostFly / где зона hockey-stars.com)
--------------------------------------------------------------------------------
УДАЛИТЬ:
  A    api  →  5.42.123.84   (VPS Timeweb — больше не нужен)

ДОБАВИТЬ:
  CNAME  api  →  jvsypfwiajuwsyuzkyda.supabase.co

TTL: 300 сек. Подождать 5–30 мин.

Проверка (PowerShell):
  nslookup api.hockey-stars.com
  → должен быть CNAME на jvsypfwiajuwsyuzkyda.supabase.co, НЕ 5.42.123.84

--------------------------------------------------------------------------------
ШАГ 2 — Supabase Dashboard
--------------------------------------------------------------------------------
Project → Settings → Custom Domains
  → api.hockey-stars.com → Active + SSL issued

Если просит TXT для SSL:
  TXT  _acme-challenge.api  →  (значение из Dashboard)

--------------------------------------------------------------------------------
ШАГ 3 — Тест БЕЗ VPN (телефон, мобильный интернет)
--------------------------------------------------------------------------------
Браузер:
  https://api.hockey-stars.com/rest/v1/
  Ожидание: JSON 401 с apikey — это УСПЕХ.

Web-диагностика (если есть):
  /_debug-connection → loadPlayers < 10 сек без VPN

--------------------------------------------------------------------------------
ШАГ 4 — VPS можно выключить
--------------------------------------------------------------------------------
Timeweb → сервер 5.42.123.84 → остановить / удалить (экономия ~300–500 р/мес)

Приложение менять НЕ нужно: EXPO_PUBLIC_SUPABASE_URL = https://api.hockey-stars.com

--------------------------------------------------------------------------------
ШАГ 5 — OTA на телефон
--------------------------------------------------------------------------------
VPN → закрыть HockeyStars → открыть → подождать 1–2 мин → закрыть → открыть

--------------------------------------------------------------------------------
Если Custom Domain медленный без VPN
--------------------------------------------------------------------------------
  1. Проверить loadPlayers в /_debug-connection (должно быть < 15 сек)
  2. Если > 60 сек — возможен throttling Cloudflare из РФ; тогда VPS как запасной
  3. Альтернатива VPS: Cloudflare Worker (см. cloudflare-worker/supabase-proxy.js)
     — edge ближе к пользователю, без своего сервера
