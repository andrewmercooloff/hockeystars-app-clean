# Альбом с карточками — генератор печатных файлов

Собирает из фото и таблицы игроков два PDF для типографии:

- `out/<команда>/<команда>-album.pdf` — журнал (A4, 8 страниц, с вылетами 3 мм);
- `out/<команда>/<команда>-cards.pdf` — карточки (листы A4, лицо + оборот, метки реза).

Дизайн повторяет альбом «СКА Стрельна 2012»: обложка, страница «Альбом» с правилами,
страницы «Команда» с местами под 9 карточек, страница «История», задняя обложка с QR HockeyStars.

## Куда положить материалы

Всё для одной команды лежит в одной папке `teams/<команда>/`:

```
teams/dobrynya/
├── team.json        ← название, сезон, год, цвета, тексты, история
├── players.csv      ← список карточек (игроки, тренеры)
├── photos/          ← фото игроков, по одному файлу на карточку
│   ├── 7.jpg        ← имя файла = игровой номер …
│   ├── Иванов Иван.jpg   ← … или «Фамилия Имя» …
│   └── ...          ← … или любое имя, указанное в колонке photo
└── assets/
    ├── logo.png     ← логотип команды (PNG с прозрачным фоном)
    ├── team.jpg     ← общее фото команды (обложка и страница «Альбом»)
    ├── cover.jpg    ← (необязательно) отдельное фото для обложки, иначе берётся team.jpg
    ├── back.jpg     ← (необязательно) фото арены для задней обложки
    ├── history.jpg  ← (необязательно) фото на страницу «История»
    ├── qr.png       ← QR-код HockeyStars на заднюю обложку
    └── gallery/     ← (необязательно) фото из жизни команды — страница-коллаж «Жизнь команды»
```

Форматы: JPG, PNG, WebP, HEIC (айфон) — конвертируется автоматически (`pip install pillow pillow-heif`);
логотип можно положить как `logo.pdf` — векторный PDF растеризуется с прозрачностью (`pip install pymupdf`).
Расширение файла не важно: ищется по имени (`logo.*`, `team.*`, `qr.*`).

Требования к фото: JPG/PNG, вертикальные, игрок в центре кадра, желательно от 1200 px по высоте
(оригиналы с телефона подходят — генератор сам уменьшит до печатного размера).
Кадрирование — `object-fit: cover` с привязкой к верху: голова не обрезается, лишнее снизу уходит.

## players.csv

Разделитель `;` или `,` (определяется автоматически), кодировка UTF-8. Порядок строк = порядок карточек в альбоме.

| колонка     | описание                                                        |
|-------------|-----------------------------------------------------------------|
| `number`    | игровой номер (у тренеров пусто)                                |
| `surname`   | Фамилия                                                         |
| `name`      | Имя (для тренеров — Имя Отчество)                               |
| `position`  | Вратарь / Защитник / Нападающий / Тренер (можно В/З/Н)          |
| `height`    | рост, см (на оборот карточки)                                   |
| `weight`    | вес, кг                                                         |
| `grip`      | хват: Левый / Правый                                            |
| `birthdate` | дата рождения, как есть: `05.03.2012`                           |
| `photo`     | имя файла в `photos/`, если оно не совпадает с номером/фамилией |
| `type`      | `player` (по умолчанию), `coach`, `legend` или `team` (общее фото) |
| `ribbon`    | метка в углу карточки (по умолчанию у тренеров «Тренерский штаб») |

Достаточно заполнить `number; surname; name; position` — остальное необязательно.
36 карточек = 4 страницы «Команда» по 9 штук. Другое количество тоже работает: страниц станет больше/меньше,
пустые места до кратности 4 добьются страницей «Мой сезон».

## team.json

- `name`, `shortName`, `city`, `year` (год рождения команды — крупно на обложке), `season`
- `colors` — `primary` (основной), `secondary` (акцентный), `accent` (золото на оборотах), `dark`, `ice`
- `cards` — размер карточки в мм (`width`/`height`, по умолчанию 55×77 — так 9 карточек влезают на страницу A4),
  `bleed` (вылет, 2 мм), `sheet` (`A4` | `A3` | `SRA3`), `layout` (`sheet` — раскладка на листах, `single` — по одной карточке на страницу)
- `album.slotStyle` — `ghost` (в ячейке бледный силуэт карточки) или `outline` (только номер и фамилия)
- `album.extraPages` — дополнительные страницы: `gallery` (коллаж из `assets/gallery/`, до 12 фото на страницу; `gallery:Свой заголовок`),
  `autographs` (ячейки для автографов всех игроков и тренеров), `stats` (таблица матчей «Мой сезон»).
  Если список пуст — коллаж добавляется автоматически при наличии фото. До кратности 4 страниц журнал добивается сам:
  сначала оставшимися фото коллажа, затем автографами, потом «Мой сезон» и «Мои заметки».
- `texts` — тексты страницы «Альбом» и задней обложки (можно с `<b>`)
- `history` — заголовок, пункты таймлайна (`years`, `title`, `text`) и блок «Цифры клуба» (`facts`)

Всё, что помечено `УТОЧНИТЬ`, — заглушки, их нужно заменить реальными данными.

## Запуск

```bash
cd print/album
npm install                    # один раз
node build.js dobrynya --preview
```

Нужен установленный Google Chrome/Chromium (используется для рендера PDF). Если он в нестандартном месте —
`PUPPETEER_EXECUTABLE_PATH=/путь/к/chrome node build.js dobrynya`.

Опции:

- `--preview` — PNG-превью всех страниц в `out/<команда>/preview/`
- `--sheet SRA3` — раскладка карточек на SRA3 (больше карточек на лист)
- `--layout single` — каждая карточка отдельной страницей с вылетами (для типографий с резкой «по одной»)
- `--keep-html` — оставить промежуточные HTML рядом с PDF (для правок дизайна)

В консоль выводится список карточек без найденного фото — для них подставляется заглушка.

## Печать

- Журнал: A4, 8 полос, вылеты 3 мм со всех сторон (страница в PDF 216×303 мм), скрепка. Полосы 2–3 и 4–5 — развороты.
- Карточки: листы A4 (или SRA3), двусторонняя печать **с переворотом по длинной стороне** — обороты уже отзеркалены.
  Резать по меткам на полях; вылет 2 мм у каждой карточки, между карточками зазор 4 мм.

## Новая команда

Скопировать `teams/dobrynya` в `teams/<новая>`, заменить `team.json`, `players.csv`, фото и ассеты, запустить `node build.js <новая>`.
