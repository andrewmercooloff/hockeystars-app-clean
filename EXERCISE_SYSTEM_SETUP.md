# Настройка системы рейтинга упражнений

## ✅ Что уже реализовано

1. **Структура данных** - созданы интерфейсы для отслеживания выполненных упражнений
2. **Кнопка "выполнено"** - добавлена в детали каждого упражнения
3. **Раздел упражнений в профиле** - показывает статистику и любимые упражнения игрока
4. **Система рейтинга** - упражнения сортируются по популярности
5. **Фильтрация по типу пользователя** - система доступна только игрокам

## ⚠️ Что нужно сделать

### 1. Добавить колонку в базу данных Supabase

Выполните следующий SQL в Supabase Dashboard (SQL Editor):

```sql
-- Добавляем колонку для статистики упражнений
ALTER TABLE players 
ADD COLUMN IF NOT EXISTS exercise_stats JSONB DEFAULT '{"completions":[],"totalCompletions":0}';

-- Добавляем комментарий к колонке
COMMENT ON COLUMN players.exercise_stats IS 'JSON статистика выполненных упражнений игрока';

-- Создаем индекс для быстрого поиска по статистике упражнений
CREATE INDEX IF NOT EXISTS idx_players_exercise_stats ON players USING GIN (exercise_stats);
```

### 2. Проверить работу системы

После добавления колонки:

1. Перезапустите приложение
2. Войдите как игрок (не тренер/скаут/звезда)
3. Перейдите в раздел "Упражнения"
4. Откройте любое упражнение и нажмите кнопку "Выполнено"
5. Проверьте профиль игрока - должен появиться раздел "Упражнения"

## 🎯 Как работает система

### Для игроков:
- В деталях каждого упражнения есть кнопка "Выполнено"
- После нажатия увеличивается счетчик выполнений
- В профиле отображается статистика упражнений
- Показываются топ-5 любимых упражнений

### Для других типов пользователей:
- Тренеры, скауты, звезды и админы не видят кнопку "Выполнено"
- Раздел упражнений в профиле показывается только для игроков

### Рейтинг упражнений:
- Упражнения сортируются по общему количеству выполнений всеми игроками
- Популярные упражнения показываются первыми
- Рядом с названием отображается количество выполнений

## 📊 Структура данных

```typescript
interface ExerciseCompletion {
  exerciseId: string;
  completedAt: string; // ISO date
  count: number; // количество выполнений
}

interface PlayerExerciseStats {
  completions: ExerciseCompletion[];
  totalCompletions: number;
  lastCompletedAt?: string;
}
```

## 🔧 Функции API

- `completeExercise(playerId, exerciseId)` - отметить упражнение как выполненное
- `getPlayerExerciseStats(playerId)` - получить статистику игрока
- `getExerciseCompletionCount(playerId, exerciseId)` - количество выполнений упражнения
- `getExerciseRankings()` - получить рейтинг популярности упражнений

## 🎉 После настройки
