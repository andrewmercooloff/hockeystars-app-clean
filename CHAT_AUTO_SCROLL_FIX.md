# Автоматическая прокрутка в чат через Deep Links

## 🐛 **Проблема**
При переходе в чат через push-уведомление (deep link) чат не прокручивался к последнему сообщению, пользователь видел старые сообщения.

## ✅ **Решение**
Добавлена автоматическая прокрутка к последнему сообщению при переходе в чат через deep link.

## 🔧 **Техническая реализация**

### **1. Модификация обработчика deep links в _layout.tsx**

#### **Было:**
```typescript
setTimeout(() => {
  router.push(deepLink as any);
}, 500);
```

#### **Стало:**
```typescript
setTimeout(() => {
  // Добавляем параметр для автоматической прокрутки в чат
  if (typeof deepLink === 'string' && deepLink.startsWith('/chat/')) {
    router.push(`${deepLink}?scrollToBottom=true` as any);
  } else {
    router.push(deepLink as any);
  }
}, 500);
```

### **2. Обработка параметра в чате**

#### **Добавлен параметр:**
```typescript
const { id, scrollToBottom } = useLocalSearchParams();
```

#### **Добавлен useEffect для автоматической прокрутки:**
```typescript
// Обработка автоматической прокрутки при переходе через deep link
useEffect(() => {
  if (scrollToBottom === 'true' && messages.length > 0 && !loading) {
    console.log('🔗 Автоматическая прокрутка в чат через deep link');
    setTimeout(() => {
      scrollViewRef.current?.scrollToEnd({ animated: true });
    }, Platform.OS === 'android' ? 300 : 200);
  }
}, [scrollToBottom, messages.length, loading]);
```

## 🎯 **Логика работы**

### **1. Отправка уведомления:**
- Push-уведомление содержит `deepLink: "/chat/senderId"`

### **2. Обработка нажатия:**
- Обработчик проверяет, начинается ли deep link с `/chat/`
- Если да, добавляет параметр `?scrollToBottom=true`
- Переходит по ссылке `/chat/senderId?scrollToBottom=true`

### **3. Открытие чата:**
- Чат получает параметр `scrollToBottom=true`
- После загрузки сообщений срабатывает useEffect
- Автоматически прокручивает к последнему сообщению

## 🧪 **Тестирование**

### **Сценарий:**
1. **Отправьте сообщение** с устройства A

3. **Нажмите на уведомление**
4. **Проверьте** - чат должен открыться и автоматически прокрутиться к последнему сообщению

## 🚀 **Преимущества**

### **1. Улучшенный UX:**
- Пользователь сразу видит новое сообщение
- Не нужно вручную прокручивать чат
- Быстрый доступ к актуальному контенту

### **2. Консистентность:**
- Работает одинаково на iOS и Android
- Учитывает платформо-специфичные задержки
- Совместимо с существующей логикой прокрутки

### **3. Надежность:**
- Проверка типов для предотвращения ошибок
- Условная логика только для чатов
- Fallback для других типов deep links

## 🔧 **Технические детали**

### **Задержки:**
- **iOS:** 200ms
- **Android:** 300ms (больше из-за особенностей рендеринга)

### **Условия срабатывания:**
- `scrollToBottom === 'true'`
- `messages.length > 0` (есть сообщения)
- `!loading` (загрузка завершена)

### **Совместимость:**
- Не влияет на обычную навигацию в чат
- Работает только при переходе через deep link
- Сохраняет существующую логику прокрутки

Теперь при переходе в чат через push-уведомление пользователь сразу видит новое сообщение! 🚀
