# 📱 Пошаговая установка Development Build на iOS

## Шаг 1: Подготовка (один раз)

### 1.1. Установите EAS CLI (если еще не установлен)
```bash
npm install -g eas-cli
```

### 1.2. Авторизуйтесь в EAS
```bash
eas login
```
Введите ваш аккаунт Expo (или создайте новый на https://expo.dev)

### 1.3. Проверьте, что вы в правильной директории проекта
```bash
cd C:\hockeystars-app-clean-old-recovered
```

---

## Шаг 2: Сборка Development Build

### 2.1. Запустите сборку для iOS
```bash
eas build --platform ios --profile development
```

**Важно:**
- Это займет **15-30 минут** (сборка происходит в облаке)
- Вам нужно будет ответить на несколько вопросов:
  - **Build for simulator?** → Выберите `No` (для реального устройства)
  - **Apple Team ID** → У вас уже указан в `eas.json`: `FAL33J6D2V`
  - Если спросит про сертификаты → Выберите автоматическую генерацию

### 2.2. Дождитесь завершения сборки
После завершения вы увидите:
```
✅ Build finished
📱 Install URL: https://expo.dev/artifacts/...
```

**Скопируйте эту ссылку!**

---

## Шаг 3: Установка на iPhone

### 3.1. Включите режим разработчика на iPhone
1. Откройте **Настройки** → **Конфиденциальность и безопасность**
2. Прокрутите вниз до раздела **Режим разработчика**
3. Включите переключатель **Режим разработчика**
4. Перезагрузите iPhone (если потребуется)

**Альтернативный путь:**
- **Настройки** → **Основные** → **VPN и управление устройством** → **Режим разработчика**

### 3.2. Откройте ссылку установки на iPhone
1. Откройте ссылку из шага 2.2 на iPhone (можно отправить себе в сообщения или открыть через Safari)
2. Нажмите **"Установить"** или **"Install"**
3. Дождитесь загрузки и установки приложения

### 3.3. Доверьте сертификату разработчика
1. После установки откройте **Настройки** → **Основные** → **VPN и управление устройством**
2. Найдите профиль разработчика (обычно "Expo" или имя вашего Apple Developer аккаунта)
3. Нажмите на профиль
4. Нажмите **"Доверять [имя профиля]"** и подтвердите

---

## Шаг 4: Подключение к Dev Server

### 4.1. Запустите dev server на компьютере
```bash
npx expo start --dev-client
```

### 4.2. Откройте приложение на iPhone
1. Найдите приложение **"HockeyStars"** на iPhone (с иконкой Expo Dev Client)
2. Откройте его

### 4.3. Подключение
**Вариант A: Автоматическое подключение**
- Если iPhone и компьютер в одной Wi-Fi сети, приложение подключится автоматически

**Вариант B: Вручную через URL**
1. В приложении встряхните iPhone (или нажмите меню разработчика)
2. Выберите **"Enter URL manually"** или **"Ввести URL вручную"**
3. Введите URL из терминала (например: `exp://192.168.1.22:8081`)

**Вариант C: Через QR-код**
- Отсканируйте QR-код из терминала камерой iPhone
- Выберите открыть в приложении HockeyStars

---

## Шаг 5: Проверка работы

После успешного подключения вы увидите:
- ✅ В терминале появятся логи приложения
- ✅ Приложение загрузится и покажет ваш интерфейс
- ✅ Все `console.log` будут видны в терминале

---

## 🔄 Ежедневное использование (после первой установки)

После того как development build установлен, вам НЕ нужно пересобирать его каждый раз:

1. **Просто запустите dev server:**
   ```bash
   npx expo start --dev-client
   ```

2. **Откройте приложение на iPhone** - оно автоматически подключится

3. **Все изменения кода применяются мгновенно** (hot reload)

---

## ⚠️ Когда нужно пересобрать development build

Пересборка нужна ТОЛЬКО если:
- ✅ Вы добавили новый нативный модуль (библиотеку с нативным кодом)
- ✅ Вы изменили настройки в `app.json` (например, permissions, bundle identifier)
- ✅ Вы обновили версию Expo SDK

**Команда для пересборки:**
```bash
eas build --platform ios --profile development
```

## 🐛 Решение проблем

### Проблема: "Нет пригодных данных" при сканировании QR-кода
**Решение:** Используйте URL вручную:
1. Скопируйте URL из терминала (например: `exp://192.168.1.22:8081`)
2. В приложении встряхните iPhone → "Enter URL manually" → вставьте URL

### Проблема: Приложение не подключается к dev server
**Решение:**
1. Убедитесь, что iPhone и компьютер в одной Wi-Fi сети
2. Проверьте файрвол на компьютере (порт 8081 должен быть открыт)
3. Попробуйте использовать tunnel:
   ```bash
   npx expo start --dev-client --tunnel
   ```

### Проблема: "Untrusted Developer" при установке
**Решение:**
1. Настройки → Основные → VPN и управление устройством
2. Найдите профиль разработчика
3. Нажмите "Доверять"

### Проблема: Сборка не запускается
**Решение:**
1. Проверьте авторизацию: `eas whoami`
2. Если не авторизован: `eas login`
3. Проверьте Apple Developer аккаунт (должен быть активен)

## 📝 Быстрая справка команд

```bash
# Авторизация в EAS
eas login

# Проверка авторизации
eas whoami

# Сборка development build для iOS
eas build --platform ios --profile development

# Запуск dev server
npx expo start --dev-client

# Запуск dev server с tunnel (если локальная сеть не работает)
npx expo start --dev-client --tunnel

# Просмотр списка сборок
eas build:list
```
