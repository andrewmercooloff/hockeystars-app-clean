# 🏒 Система годов для тренеров - Инструкция

## ✅ Что реализовано:

### 1. База данных
- Добавлено поле `coach_years` в таблицу `players` (массив целых чисел)
- Создан индекс для быстрого поиска тренеров по годам

### 2. UI для тренера
В профиле тренера (режим редактирования) появилась новая секция **"Тренирует годы"**:
- Доступные годы: **2021 - 2007** (15 лет)
- Тренер может выбрать несколько годов
- Выбранные годы подсвечиваются красным цветом
- Горизонтальная прокрутка если годов много

### 3. Фильтрация на главной странице
- **Тренеры показываются ТОЛЬКО в тех годах, которые они выбрали**
- Если у тренера не указаны годы - он показывается везде (для обратной совместимости)
- Если год не выбран на главной странице - тренеры с указанными годами НЕ показываются

## 🚀 Инструкция по установке:

### Шаг 1: Добавьте поле в базу данных

Выполните SQL в Supabase Dashboard:

```sql
-- Добавляем поле для годов тренера
ALTER TABLE public.players 
ADD COLUMN IF NOT EXISTS coach_years INTEGER[];

-- Добавляем комментарий
COMMENT ON COLUMN public.players.coach_years IS 'Годы рождения игроков, которых тренирует этот тренер (только для status=coach)';

-- Создаем индекс для быстрого поиска
CREATE INDEX IF NOT EXISTS idx_players_coach_years 
ON public.players USING GIN (coach_years);
```

### Шаг 2: Перезапустите приложение

```bash
npx expo start --clear
```

## 📱 Как использовать:

### Для тренера:

1. **Войдите в свой профиль**
2. **Нажмите кнопку "Редактировать"**
3. **Найдите секцию "Тренирует годы"**
4. **Выберите годы** рождения игроков, с которыми вы работаете:
   - Нажмите на год, чтобы выбрать
   - Нажмите еще раз, чтобы отменить выбор
   - Можно выбрать несколько годов
5. **Сохраните изменения**

### На главной странице:

1. **Выберите год рождения** в фильтре
2. **Тренеры будут показаны** только если они выбрали этот год в своем профиле
3. **Звезды и магазины** показываются как раньше (во всех годах)

### В режиме просмотра:
```
Тренирует годы: 2021, 2019, 2018, 2017
```

### В режиме редактирования:
```
[2021] [2020] [2019] [2018] [2017] [2016] ...
  ✓      ✗      ✓      ✓      ✓      ✗
```
- ✓ = красная кнопка (выбрано)
- ✗ = серая кнопка (не выбрано)
