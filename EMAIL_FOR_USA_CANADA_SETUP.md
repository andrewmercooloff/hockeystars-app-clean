## 🎯 Как это работает

### Регистрация:
1. Пользователь выбирает страну **США** или **Канада**
2. Автоматически показывается поле **Email** вместо телефона
3. Пользователь вводит email
4. Код отправляется на email через Supabase Edge Function
5. Пользователь вводит код и регистрируется

### Логин:
1. Пользователь выбирает **Email (USA/Canada)** или **Phone**
2. Вводит email или телефон
3. Код отправляется соответственно на email или SMS
4. Пользователь вводит код и входит

## 📋 Что нужно проверить

### 1. Supabase Edge Function развернута?

Используется функция `send-verification-email`, которая уже настроена для отправки писем родителям.

Проверь, что функция развернута:
```bash
supabase functions list
```

Если нет - разверни:
```bash
supabase functions deploy send-verification-email
```

### 2. Настроен ли Resend API Key?

В Supabase Dashboard → **Settings** → **Edge Functions** → **Secrets**:
- Должен быть настроен `RESEND_API_KEY` (уже настроен для родительских писем)

### 3. Проверь работу

1. Выбери страну **США** или **Канада** в регистрации
2. Должно появиться поле **Email**
3. Введи email и отправь код
4. Проверь почту - должен прийти код на английском
