# Инструкция по проверке видео для App Store

## Быстрая проверка параметров видео

### Вариант 1: Использование FFmpeg (рекомендуется)

1. **Установите FFmpeg** (если еще не установлен):
   ```powershell
   winget install ffmpeg
   ```
   или скачайте с https://ffmpeg.org/download.html

2. **Проверьте параметры видео**:
   ```powershell
   ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate,duration -show_entries format=size,duration -of json "C:\Users\ВашеИмя\Downloads\IMG_5198.MOV"
   ```

3. **Проверьте аудио**:
   ```powershell
   ffprobe -v error -select_streams a:0 -show_entries stream=codec_name,sample_rate,channels,bit_rate -of json "C:\Users\ВашеИмя\Downloads\IMG_5198.MOV"
   ```

### Вариант 2: Использование MediaInfo (GUI)

1. Скачайте MediaInfo: https://mediaarea.net/MediaInfo
2. Откройте видео в MediaInfo
3. Проверьте параметры согласно требованиям ниже

### Вариант 3: Использование скрипта PowerShell

Запустите скрипт `check_video.ps1` с указанием полного пути:
```powershell
.\check_video.ps1 -VideoPath "C:\Users\ВашеИмя\Downloads\IMG_5198.MOV"
```

## Требования App Store для видео-превью

### ✅ Обязательные параметры:

1. **Формат файла**: `.mov`, `.m4v`, или `.mp4`
2. **Кодек видео**: H.264 (AVC) или ProRes 422 (HQ)
3. **Частота кадров**: максимум 30 fps
4. **Длительность**: от 15 до 30 секунд
5. **Размер файла**: максимум 500 MB
6. **Разрешение**: должно точно соответствовать размеру скриншотов для выбранного устройства

### ✅ Параметры аудио (если есть):

1. **Кодек**: AAC
2. **Битрейт**: 256 kbps
3. **Частота дискретизации**: 44.1 kHz или 48 kHz
4. **Каналы**: стерео (2 канала)

### ✅ Контент видео:

- Только скриншоты/запись экрана из приложения
- Без промо-текста, цен, призывов к действию
- Без внешних элементов (не из приложения)

## Типичные разрешения для разных устройств:

- **iPhone портрет**: 1080x1920 или 1290x2796 (iPhone 14 Pro Max)
- **iPhone ландшафт**: 1920x1080 или 2796x1290
- **iPad портрет**: 2048x2732
- **iPad ландшафт**: 2732x2048

## Команда для исправления видео (FFmpeg)

Если видео не соответствует требованиям, используйте эту команду для конвертации:

```powershell
ffmpeg -i "C:\Users\ВашеИмя\Downloads\IMG_5198.MOV" `
  -c:v libx264 `
  -profile:v high `
  -level 4.0 `
  -pix_fmt yuv420p `
  -r 30 `
  -c:a aac `
  -b:a 256k `
  -ar 48000 `
  -ac 2 `
  -t 30 `
  "C:\Users\ВашеИмя\Downloads\IMG_5198_fixed.mov"
```

**Параметры команды:**
- `-c:v libx264` - кодек H.264
- `-profile:v high` - профиль High для лучшей совместимости
- `-r 30` - частота кадров 30 fps
- `-c:a aac` - аудио кодек AAC
- `-b:a 256k` - битрейт аудио 256 kbps
- `-ar 48000` - частота дискретизации 48 kHz
- `-ac 2` - стерео (2 канала)
- `-t 30` - ограничение до 30 секунд (если видео длиннее)

## Частые проблемы и решения:

### Проблема: "Видео не принимается"
**Возможные причины:**
1. Кодек не H.264 (например, H.265/HEVC)
2. Частота кадров больше 30 fps
3. Неправильный аудио кодек или параметры
4. Разрешение не соответствует размеру скриншотов
5. Длительность меньше 15 или больше 30 секунд

### Проблема: "Default poster frame setting"
Это просто настройка кадра-превью. Можно оставить по умолчанию (Apple выберет первый кадр) или выбрать конкретный кадр вручную.
