# 🏒 Инструкция по миграции упражнений в базу данных

## 📋 Обзор изменений

Мы переносим систему упражнений из статических файлов в базу данных Supabase для:
- ✅ Легкого добавления новых упражнений
- ✅ Централизованного управления переводами
- ✅ Масштабируемости системы
- ✅ Возможности администрирования через веб-интерфейс

## 🚀 Шаги для применения изменений

### 1. Откройте Supabase Dashboard
- Перейдите на https://supabase.com/dashboard
- Войдите в свой аккаунт
- Выберите проект `hockeystars-app`

### 2. Создайте таблицу exercises
- В левом меню найдите "SQL Editor"
- Нажмите "New query" для создания нового запроса
- Скопируйте содержимое файла `database/create_exercises_table.sql`
- Вставьте в SQL Editor и нажмите "Run"

### 3. Мигрируйте данные упражнений
- Создайте новый SQL запрос
- Скопируйте содержимое файла `database/migrate_exercises_data.sql`
- Вставьте в SQL Editor и нажмите "Run"

### 4. Проверьте результат
Выполните следующий запрос для проверки:
```sql
SELECT 
  exercise_id, 
  title_ru, 
  title_en, 
  category, 
  difficulty,
  is_active
FROM exercises 
ORDER BY exercise_id::integer;
```

## 📊 Структура таблицы exercises

### Основные поля:
- `id` - автоинкрементный первичный ключ
- `exercise_id` - уникальный ID упражнения (1, 2, 3, etc.)
- `category` - категория упражнения
- `duration` - продолжительность
- `difficulty` - уровень сложности
- `is_active` - активно ли упражнение

### Русские переводы:
- `title_ru` - название на русском
- `description_ru` - описание на русском
- `benefits_ru` - польза (JSON массив)
- `instructions_ru` - инструкции (JSON массив)
- `tips_ru` - советы (JSON массив)
- `equipment_ru` - оборудование
- `calories_ru` - калории

### Английские переводы:
- `title_en` - название на английском
- `description_en` - описание на английском
- `benefits_en` - польза (JSON массив)
- `instructions_en` - инструкции (JSON массив)
- `tips_en` - советы (JSON массив)
- `equipment_en` - оборудование
- `calories_en` - калории

## 🔒 Безопасность

- Включен Row Level Security (RLS)
- Все пользователи могут читать активные упражнения
- Только администраторы могут изменять упражнения
- Созданы индексы для быстрого поиска

## 📈 Преимущества новой системы

1. **Централизованное управление** - все упражнения в одном месте
2. **Многоязычность** - легкое добавление новых языков
3. **Версионность** - отслеживание изменений через `updated_at`
4. **Масштабируемость** - не нужно пересобирать приложение
5. **Администрирование** - управление через Supabase Dashboard
