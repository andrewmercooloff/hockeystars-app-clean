# Чеклист для публикации в App Store

## ✅ Обязательные требования

### 1. Apple Developer Account
- [ ] **Активный Apple Developer Program** (99$/год)
  - Без него публикация невозможна
  - Регистрация: https://developer.apple.com/programs/
  - Обычно одобрение занимает 1-2 дня

### 2. Сертификаты и профили (для production)
- [ ] **Distribution Certificate** (Production)
  - Создается в Apple Developer Portal
  - Используется для подписи production сборки
- [ ] **App Store Provisioning Profile**
  - Создается для вашего App ID
  - Привязывается к Distribution Certificate
- [ ] **App ID** (Bundle Identifier)
  - Должен быть уникальным (например: `com.yourcompany.hockeystars`)
  - Уже должен быть настроен в `app.json` или `app.config.js`

### 3. Иконки приложения
- [ ] **App Icon** (1024x1024 px, PNG, без альфа-канала)
  - Обязательно для App Store
  - Размещается в `assets/icon.png` или настраивается в `app.json`
  - Требования:
    - Квадрат 1024x1024 пикселей
    - Формат PNG
    - Без прозрачности
    - Без скругленных углов (Apple добавит автоматически)
    - Без текста "App Store" или других меток

### 4. Скриншоты для App Store
- [ ] **Скриншоты для iPhone** (обязательно)
  - iPhone 6.7" (iPhone 14 Pro Max, 15 Pro Max): 1290 x 2796 px
  - iPhone 6.5" (iPhone 11 Pro Max, XS Max): 1242 x 2688 px
  - iPhone 5.5" (iPhone 8 Plus): 1242 x 2208 px
  - Минимум 1 скриншот, рекомендуется 3-10
- [ ] **Скриншоты для iPad** (если поддерживается)
  - iPad Pro 12.9": 2048 x 2732 px
  - iPad Pro 11": 1668 x 2388 px
  - Минимум 1 скриншот, рекомендуется 3-10

### 5. Описание приложения (App Store Connect)
- [ ] **Название приложения** (до 30 символов)
- [ ] **Подзаголовок** (до 30 символов) - опционально
- [ ] **Описание** (до 4000 символов)
  - Должно быть на всех языках, которые вы поддерживаете
  - Включает ключевые слова для поиска
- [ ] **Ключевые слова** (до 100 символов, через запятую)
  - Используются для поиска в App Store
- [ ] **Промо-текст** (до 170 символов) - опционально
  - Может обновляться без новой версии

### 6. Privacy Policy (Обязательно!)
- [ ] **URL Privacy Policy**
  - Должен быть доступен публично (HTTPS)
  - Обязателен для всех приложений
  - Должен описывать:
    - Какие данные собираются
    - Как используются данные
    - Как данные передаются третьим лицам
    - Права пользователей
- [ ] **Privacy Policy на всех языках**, которые поддерживает приложение

### 7. Контактная информация
- [ ] **URL поддержки** (Support URL)
  - Должен быть доступен публично
  - Может быть сайт, email или форма обратной связи
- [ ] **Marketing URL** (опционально)
  - Сайт приложения или промо-страница

### 8. Категории и возрастной рейтинг
- [ ] **Основная категория** (например: Sports, Games)
- [ ] **Вторичная категория** (опционально)
- [ ] **Возрастной рейтинг**
  - Заполняется через опросник в App Store Connect
  - Влияет на доступность приложения

### 9. Цена и доступность
- [ ] **Цена** (бесплатно или платно)
- [ ] **Страны**, где приложение будет доступно
- [ ] **Соглашение о ценах** (если платное)

### 10. Технические требования

#### Версия приложения
- [ ] **Версия** (например: 1.0.0)
  - Указывается в `app.json` или `app.config.js`
  - Формат: `MAJOR.MINOR.PATCH`
- [ ] **Build Number**
  - Уникальный номер сборки для каждой версии
  - Увеличивается с каждой загрузкой в App Store Connect

#### Минимальная версия iOS
- [ ] **Минимальная версия iOS**
  - Проверьте в `app.json`: `"ios": { "deploymentTarget": "13.0" }`
  - Рекомендуется: iOS 13.0 или выше

#### Разрешения (Permissions)
- [ ] **Описание использования разрешений**
  - Камера (если используется)
  - Фото (если используется)
  - Уведомления (push notifications)
  - Микрофон (если используется для записи)
  - Локация (если используется)
  - Все разрешения должны быть описаны в Privacy Policy

### 11. Подготовка сборки

#### Expo EAS Build
- [ ] **EAS Build настроен**
  ```bash
  npm install -g eas-cli
  eas login
  eas build:configure
  ```
- [ ] **Production build создан**
  ```bash
  eas build --platform ios --profile production
  ```
- [ ] **Build загружен в App Store Connect**
  - Через EAS Submit или вручную через Transporter

#### Проверка перед сборкой
- [ ] **Все зависимости установлены**
- [ ] **Нет ошибок компиляции**
- [ ] **Тестирование на реальных устройствах**
- [ ] **Проверка всех функций**
- [ ] **Проверка производительности**

### 12. App Store Connect настройки

#### App Information
- [ ] **Bundle ID** совпадает с настройками проекта
- [ ] **SKU** (уникальный идентификатор)
- [ ] **User Access** (Full Access или App Manager)

#### App Review Information
- [ ] **Контактная информация для ревьюеров**
  - Имя, фамилия, телефон, email
- [ ] **Примечания для ревьюеров** (опционально)
  - Тестовый аккаунт (если требуется)
  - Инструкции по тестированию
  - Особенности приложения

#### Version Information
- [ ] **Что нового в этой версии** (Release Notes)
  - До 4000 символов
  - Описание изменений и улучшений

### 13. Требования к контенту

#### Контент приложения
- [ ] **Нет запрещенного контента**
  - Насилие, оскорбления, дискриминация
  - Нелегальный контент
  - Контент для взрослых (если не указан соответствующий рейтинг)
- [ ] **Соответствие Guidelines**
  - Human Interface Guidelines
  - App Store Review Guidelines

#### Функциональность
- [ ] **Приложение работает без критических ошибок**
- [ ] **Все ссылки работают**
- [ ] **Нет пустых экранов или заглушек**
- [ ] **Приложение не крашится**

### 14. Тестирование

#### Pre-release Testing
- [ ] **TestFlight тестирование**
  - Внутреннее тестирование (Internal Testing)
  - Внешнее тестирование (External Testing) - до 10,000 тестеров
- [ ] **Обратная связь от тестеров**
- [ ] **Исправление найденных багов**

### 15. Юридические требования

#### Соглашения
- [ ] **Paid Applications Agreement** (если платное)
- [ ] **Free Applications Agreement**
- [ ] **Apple Developer Program License Agreement** (принят)

#### Соблюдение законов
- [ ] **GDPR** (если приложение доступно в ЕС)
- [ ] **COPPA** (если приложение для детей)
- [ ] **Другие местные законы** (в зависимости от стран)

### 16. Дополнительные настройки (опционально)

#### In-App Purchases
- [ ] Настроены в App Store Connect
- [ ] Тестирование покупок
- [ ] Описания продуктов

#### Subscriptions
- [ ] Настроены подписки (если есть)
- [ ] Цены и периоды
- [ ] Описания подписок

#### App Clips
- [ ] Настроены App Clips (если используются)

#### Widgets
- [ ] Настроены виджеты (если используются)

## 📋 Процесс публикации

### Шаг 1: Подготовка
1. Убедитесь, что все пункты чеклиста выполнены
2. Создайте production build через EAS
3. Загрузите build в App Store Connect

### Шаг 2: Настройка в App Store Connect
1. Войдите в App Store Connect
2. Создайте новое приложение (если первая публикация)
3. Заполните всю информацию
4. Загрузите скриншоты и иконку
5. Добавьте описание и ключевые слова
6. Настройте цену и доступность

### Шаг 3: Отправка на ревью
1. Выберите build для ревью
2. Заполните "What's New in This Version"
3. Добавьте примечания для ревьюеров (если нужно)
4. Нажмите "Submit for Review"

### Шаг 4: Ожидание ревью
- Обычно занимает 24-48 часов
- Может быть отклонено с комментариями
- После одобрения приложение автоматически публикуется

### Шаг 5: После публикации
1. Мониторинг отзывов
2. Отслеживание метрик
3. Подготовка обновлений

## ⚠️ Частые причины отклонения

1. **Отсутствие Privacy Policy** - самая частая причина
2. **Неполная информация** - не заполнены обязательные поля
3. **Краши приложения** - приложение не работает
4. **Нарушение Guidelines** - контент или функциональность
5. **Неработающие ссылки** - Support URL или Privacy Policy недоступны
6. **Несоответствие описания** - описание не соответствует функциональности
7. **Отсутствие функциональности** - приложение выглядит как заглушка

- **Критические обновления** могут быть ускорены через Expedited Review
- Всегда тестируйте на реальных устройствах перед отправкой
- Сохраняйте резервные копии всех сертификатов и профилей
