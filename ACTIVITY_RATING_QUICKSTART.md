## 🔧 Полезные команды

### Очистка данных активности:
Выполните в Supabase Dashboard → SQL Editor:
```sql
TRUNCATE TABLE public.activity_log;
TRUNCATE TABLE public.activity_points;
```

### Проверка текущих данных:
```sql
-- Топ-10 активных пользователей
SELECT user_id, points 
FROM activity_points 
ORDER BY points DESC 
LIMIT 10;

-- Последние действия
SELECT * FROM activity_log 
ORDER BY created_at DESC 
LIMIT 20;
```

## 🐛 Если что-то не работает:

1. **Рейтинг не отображается:**
   - Проверьте, что вы вошли в свой профиль или являетесь администратором
   
2. **Очки не начисляются:**
   - Проверьте консоль на наличие ошибок
   - Убедитесь, что таблицы созданы в Supabase
   
3. **Очки начисляются слишком часто:**
   - Это ожидаемое поведение при быстром изменении профиля
   - LOGIN трекается только 1 раз за сессию
