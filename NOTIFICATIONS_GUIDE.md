# 📢 Система уведомлений о изменениях статистики

## 🎯 Описание
Система автоматически отправляет уведомления друзьям, когда игрок изменяет свою статистику или нормативы.

## 🔧 Как это работает

### 1. Отслеживание изменений
- При обновлении профиля игрока (`updatePlayer`) система сравнивает старые и новые значения
- Отслеживаются поля статистики: `goals`, `assists`, `games`
- Отслеживаются нормативы: `pullUps`, `pushUps`, `plankTime`, `sprint100m`, `longJump`, `jumpRope`

### 2. Создание уведомлений
- Для каждого друга создается уведомление типа `stats_change`
- Уведомление содержит детальную информацию об изменениях
- Также создается уведомление для самого игрока

### 3. Отображение уведомлений
- В экране уведомлений используется специальный компонент `StatsChangeNotification`
- Показывается имя игрока, время изменения и детали изменений
- Клик по уведомлению переводит к профилю игрока

## 📱 Компоненты

### `StatsChangeNotification`
- Отображает изменения статистики в удобном формате
- Показывает старые и новые значения
- Выделяет положительные изменения зеленым цветом
- Форматирует значения в зависимости от типа поля

### `notifyFriendsAboutChanges`
- Основная функция для отправки уведомлений
- Получает список друзей игрока
- Создает уведомления для каждого друга
- Сохраняет уведомления в базу данных

## 🗄️ Структура данных

### Уведомление в базе данных
```json
{
  "id": "uuid",
  "user_id": "friend_id",
  "type": "stats_change",
  "title": "Изменения в статистике",
  "message": "Игрок обновил: голов: +1, передач: +2",
  "data": {
    "changes": [
      {
        "field": "goals",
        "oldValue": 5,
        "newValue": 6,
        "change": 1,
        "timestamp": "2024-09-22T20:00:00Z"
      }
    ],
    "changedPlayerId": "player_id",
    "changedPlayerName": "Имя игрока"
  },
  "created_at": "2024-09-22T20:00:00Z",
  "is_read": false
}
```

## 🎨 Стилизация
- Уведомления о статистике имеют специальный дизайн в стиле сообщений
- Фото игрока слева (или иконка по умолчанию)
- Информация об уведомлении справа
- Детальное отображение изменений с цветовой индикацией (красный для положительных изменений)

## 🔄 Интеграция
- Система интегрирована в `updatePlayer` функцию
- Автоматически работает при любых изменениях статистики
- Не требует дополнительной настройки

## 📊 Статистика
- Отслеживает 3 поля статистики
- Отслеживает 6 полей нормативов
- Поддерживает неограниченное количество друзей
- Автоматически форматирует значения
