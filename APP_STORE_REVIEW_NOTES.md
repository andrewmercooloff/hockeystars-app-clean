# 📝 Примечания для App Store Review

## Инструкции для ревьюеров

Скопируйте этот текст в раздел **"App Review Information"** → **"Notes"** в App Store Connect:

---

```
УНИВЕРСАЛЬНЫЙ КОД ДЛЯ ВХОДА (для тестирования без SMS):

Для входа в приложение используйте универсальный секретный код:

1. Введите ЛЮБОЙ номер телефона (например: +1234567890)
2. Нажмите "Отправить код" (Send Code)
3. В поле "Код подтверждения" введите: 291019
4. Нажмите "Подтвердить" (Verify)

Секретный код работает для ЛЮБОГО номера телефона и не требует получения SMS.

---

UNIVERSAL LOGIN CODE (for testing without SMS):

To log in to the app, use the universal secret code:

1. Enter ANY phone number (e.g., +1234567890)
2. Click "Send Code"
3. In the "Verification Code" field, enter: 291019
4. Click "Verify"

The secret code works for ANY phone number and does not require receiving SMS.
```

---

## Где добавить:

1. Войдите в [App Store Connect](https://appstoreconnect.apple.com/)
2. Выберите ваше приложение
3. Перейдите в **"App Store"** → **"App Review Information"**
4. Найдите поле **"Notes"**
5. Вставьте текст выше
6. Сохраните

---
