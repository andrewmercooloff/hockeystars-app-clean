# Исправление проблемы с аудио-радаром в TestFlight

## Проблема

В TestFlight (production build):
- Микрофон включается ✅
- Пики громкости НЕ двигаются ❌
- Звук НЕ определяется ❌

В development build все работает корректно.

## Причина

**Это НЕ связано с проблемой версий зависимостей** (которая влияет только на физику шайб).

Проблема в том, что:
1. `react-native-audio-recorder-player` может не работать правильно в production сборке
2. Callback `addRecordBackListener` может не вызываться в production
3. Метеринг может не возвращать данные (`currentMetering` всегда `-160` или `undefined`)
4. Нативная интеграция модуля может быть неправильно скомпилирована

## Решение

### Вариант 1: Добавить fallback на expo-av (рекомендуется)

Expo-av более стабилен в production сборках и лучше интегрирован с Expo.

**Преимущества:**
- Работает стабильно в production
- Правильно интегрирован с Expo
- Поддерживает метеринг через `getStatusAsync()`
- Не требует дополнительных нативных настроек

**Недостатки:**
- Нужно переписать часть кода
- Метеринг работает через polling (setInterval), а не через callback

### Вариант 2: Исправить react-native-audio-recorder-player

**Проблемы:**
- Модуль может требовать дополнительной настройки в production
- Нативная интеграция может быть неправильной
- Callback может не работать из-за оптимизации production сборки

**Решения:**
1. Проверить, что модуль правильно скомпилирован в нативный код
2. Убедиться, что callback не оптимизируется компилятором
3. Добавить больше проверок и fallback'ов

### Вариант 3: Гибридный подход

Использовать expo-av как основной метод, а react-native-audio-recorder-player как fallback.

## Рекомендуемый план действий

3. **Потом:** Протестируй локально
   - Убедись, что fallback работает
   - Проверь, что пики двигаются

4. **Наконец:** Собери новую версию
   - С исправлениями
   - Протестируй в TestFlight

## Диагностика проблемы

### Проверка 1: Работает ли callback?

В коде есть проверка:
```typescript
setTimeout(() => {
  if (callbackCallCount === 0) {
    console.error('❌ [iOS] КРИТИЧНО: Callback не вызывается!');
  }
}, 2000);
```

**Если callback не вызывается:**
- Модуль не работает в production
- Нужен fallback на expo-av

### Проверка 2: Возвращает ли метеринг данные?

В коде есть логирование:
```typescript
if (callbackCallCount <= 20) {
  console.log(`🎤 [iOS] Callback #${callbackCallCount}, данные:`, JSON.stringify(logData));
}
```

**Если `currentMetering` всегда `-160` или `undefined`:**
- Метеринг не включен или не работает
- Нужно проверить параметры `startRecorder`

### Проверка 3: Правильно ли инициализирован модуль?

В коде есть проверка типа модуля:
```typescript
console.log('📦 [iOS] Тип AudioRecorderPlayerModule:', typeof AudioRecorderPlayerModule);
```

**Если тип неправильный в production:**
- Модуль не правильно импортирован
- Нужно исправить импорт
