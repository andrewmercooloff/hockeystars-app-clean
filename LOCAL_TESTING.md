## 🛠 Пошаговая настройка

### **Шаг 1: Установка MongoDB**

#### **Windows:**
1. Скачайте MongoDB Community Server: https://www.mongodb.com/try/download/community
2. Установите с настройками по умолчанию
3. MongoDB будет доступен по адресу: `mongodb://localhost:27017`

#### **macOS:**
```bash
brew install mongodb-community
brew services start mongodb-community
```

#### **Linux (Ubuntu):**
```bash
sudo apt update
sudo apt install mongodb
sudo systemctl start mongod
sudo systemctl enable mongod
```

### **Шаг 2: Быстрый запуск**

#### **Windows:**
```bash
# В папке проекта
start-local.bat
```

#### **macOS/Linux:**
```bash
# В папке проекта
chmod +x start-local.sh
./start-local.sh
```

### **Шаг 3: Ручная настройка (если скрипт не работает)**

#### **Запуск сервера:**
```bash
cd server
npm install
cp env.example .env
# Отредактируйте .env файл
npm run dev
```

#### **Запуск клиента:**
```bash
# В корневой папке проекта
npm install
# Создайте .env файл
echo "EXPO_PUBLIC_API_URL=http://localhost:5000/api" > .env
echo "EXPO_PUBLIC_SOCKET_URL=http://localhost:5000" >> .env
npm start
```

## 🧪 Сценарии тестирования

### **1. Тестирование регистрации и авторизации**

1. **Запустите приложение** на двух разных устройствах/эмуляторах
2. **Зарегистрируйтесь** на первом устройстве
3. **Проверьте**, что пользователь появился в списке на втором устройстве
4. **Войдите** с другого устройства под тем же аккаунтом

### **2. Тестирование синхронизации профилей**

1. **Отредактируйте профиль** на первом устройстве
2. **Проверьте**, что изменения видны на втором устройстве
3. **Добавьте фотографии** и проверьте синхронизацию
4. **Измените статистику** и нормативы

### **3. Тестирование системы друзей**

1. **Зарегистрируйте двух пользователей** на разных устройствах
2. **Отправьте запрос дружбы** с одного устройства
3. **Проверьте уведомление** на втором устройстве
4. **Примите запрос** и проверьте синхронизацию

### **4. Тестирование чата**

1. **Добавьте друг друга в друзья**
2. **Отправьте сообщение** с одного устройства
3. **Проверьте получение** на втором устройстве в реальном времени
4. **Проверьте историю сообщений**

### **5. Тестирование поиска**

1. **Создайте несколько пользователей** с разными данными
2. **Используйте поиск** по имени, команде, позиции
3. **Проверьте фильтры** по статусу (игрок, тренер, скаут)

## 🐛 Решение проблем

### **Проблема: MongoDB не запускается**
```bash
# Windows
net start MongoDB

# macOS
brew services restart mongodb-community

# Linux
sudo systemctl restart mongod
```

### **Проблема: Порт 5000 занят**
```bash
# Измените порт в server/.env
PORT=5001

# И в клиентском .env
EXPO_PUBLIC_API_URL=http://localhost:5001/api
EXPO_PUBLIC_SOCKET_URL=http://localhost:5001
```

### **Проблема: Ошибки CORS**
```bash
# Проверьте CLIENT_URL в server/.env
CLIENT_URL=http://localhost:3000
```

### **Проблема: Не загружаются изображения**
```bash
# Настройте Cloudinary или используйте локальное хранилище
# В server/.env добавьте:
CLOUDINARY_CLOUD_NAME=your-name
CLOUDINARY_API_KEY=your-key
CLOUDINARY_API_SECRET=your-secret
```

## 📱 Тестирование на разных устройствах

### **Локальная сеть:**
1. **Найдите IP адрес** вашего компьютера
2. **Измените URL** в клиентском .env:
   ```
   EXPO_PUBLIC_API_URL=http://192.168.1.100:5000/api
   EXPO_PUBLIC_SOCKET_URL=http://192.168.1.100:5000
   ```
3. **Откройте порт 5000** в файрволе
4. **Подключитесь** с телефона по IP адресу

### **Эмуляторы:**
1. **Android Studio** - Android эмулятор
2. **Xcode** - iOS симулятор (только macOS)
3. **Expo Go** - на реальных устройствах
