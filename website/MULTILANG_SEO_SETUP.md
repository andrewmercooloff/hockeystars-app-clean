# Настройка многоязычности для SEO

## ✅ Что было сделано

1. **Создана отдельная английская страница** `index-en.html` с правильными английскими метатегами
2. **Обновлены hreflang теги** в обеих версиях для правильного определения языков поисковыми системами
3. **Настроена маршрутизация** через `.htaccess` для `/en` → `index-en.html`
4. **Обновлен JavaScript** для переключения между страницами вместо только изменения языка

## 📁 Структура файлов

- `index.html` - русская версия (по умолчанию на `/`)
- `index-en.html` - английская версия (доступна на `/en`)
- `.htaccess` - правила маршрутизации

## 🔍 SEO метатеги

### Русская версия (`index.html`):
- `lang="ru"` в `<html>`
- `og:locale="ru_RU"`
- Русские метатеги title, description
- `hreflang="ru"` указывает на `https://hockey-stars.com/`
- `hreflang="en"` указывает на `https://hockey-stars.com/en`

### Английская версия (`index-en.html`):
- `lang="en"` в `<html>`
- `og:locale="en_US"`
- Английские метатеги title, description
- `hreflang="ru"` указывает на `https://hockey-stars.com/`
- `hreflang="en"` указывает на `https://hockey-stars.com/en`

## 🔄 Как работает переключение языка

1. **При клике на кнопку языка:**
   - Если выбран английский и находимся на `/` → редирект на `/en`
   - Если выбран русский и находимся на `/en` → редирект на `/`
   - Если уже на правильной странице → просто меняется язык через JavaScript

2. **При загрузке страницы:**
   - Если URL содержит `/en` → автоматически устанавливается английский язык
   - Иначе → определяется язык из localStorage, URL параметров или браузера
