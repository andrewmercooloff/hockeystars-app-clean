# 🚀 Realtime Cache Management System

## 📋 Обзор

Система автоматического управления кешем с использованием **Supabase Realtime** для мгновенного обновления данных при изменениях в базе данных.

## ✨ Возможности

- **Автоматическая очистка кеша** при изменениях данных
- **Realtime подписки** на все критичные таблицы
- **Централизованное управление** кешем
- **Оптимизированная производительность** с мгновенными обновлениями

## 🔧 Как это работает

### 1. Realtime Подписки

Система подписывается на изменения в следующих таблицах:

| Таблица | События | Действие |
|---------|---------|----------|
| `players` | UPDATE | Очистка кеша игрока |
| `player_museum` | INSERT/UPDATE/DELETE | Очистка кеша музея |
| `player_teams` | INSERT/UPDATE/DELETE | Очистка кеша команд |
| `friend_requests` | INSERT/UPDATE/DELETE | Очистка кеша дружбы |

### 2. Автоматическая Очистка Кеша

Когда происходит изменение в базе данных:

```typescript
// Пример: Кто-то добавил подарок в музей
// 1. Supabase отправляет Realtime событие
// 2. CacheManager получает событие
// 3. Автоматически очищается кеш музея
// 4. При следующем заходе данные загружаются свежие
```

### 3. Типы Кеша

- **`player_${playerId}`** - данные игрока (10 мин)
- **`museum_${playerId}`** - подарки игрока (10 мин)
- **`exercise_stats_${playerId}`** - статистика упражнений (10 мин)
- **`teams_${playerId}`** - команды игрока (10 мин)
- **`friends_${playerId}`** - список друзей (10 мин)
- **`friendship_${userId1}_${userId2}`** - статус дружбы (5 мин)

## 🔄 Примеры Работы

### Сценарий 1: Добавление подарка
```
1. Администратор отправляет подарок игроку
2. Данные сохраняются в БД (таблица player_museum)
3. Supabase отправляет Realtime событие INSERT
4. CacheManager получает событие
5. Автоматически очищается кеш музея игрока
6. При следующем заходе в профиль - свежие данные!
```

### Сценарий 2: Выполнение упражнения
```
1. Игрок выполняет упражнение
2. Обновляется поле exercise_stats в таблице players
3. Supabase отправляет Realtime событие UPDATE
4. CacheManager получает событие
5. Автоматически очищается кеш упражнений
6. Статистика обновляется мгновенно!
```

### Сценарий 3: Изменение дружбы
```
1. Кто-то принимает запрос в друзья
2. Обновляется таблица friend_requests
3. Supabase отправляет Realtime событие UPDATE
4. CacheManager получает событие
5. Очищается кеш дружбы и списка друзей
6. Статус дружбы обновляется мгновенно!
```

## 🛠️ Техническая Реализация

### CacheManager Class

```typescript
export class CacheManager {
  // Singleton pattern для централизованного управления
  static getInstance(): CacheManager
  
  // Настройка всех Realtime подписок
  async setupRealtimeSubscriptions(userId: string): Promise<void>
  
  // Отключение всех подписок
  async disconnect(): Promise<void>
  
  // Приватные методы очистки кеша
  private async clearPlayerCache(playerId: string): Promise<void>
  private async clearMuseumCache(playerId: string): Promise<void>
  // ... и другие
}
```

### Интеграция в Layout

```typescript
// В app/_layout.tsx
React.useEffect(() => {
  if (!currentUser) return;
  
  // Настраиваем Realtime подписки для кеша
  cacheManager.setupRealtimeSubscriptions(currentUser.id);
  
  return () => {
    // Отключаем подписки при размонтировании
    cacheManager.disconnect();
  };
}, [currentUser?.id]);
```
