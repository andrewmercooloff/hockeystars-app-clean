# Калибровка измерения скорости шайбы

## Принцип работы

Система измеряет скорость шайбы по видео, отслеживая её движение через зону калибровки.

## Как настроить точное расстояние

### Шаг 1: Измерьте точное расстояние от телефона до шайбы

1. Положите шайбу на лед
2. Откройте экран измерения скорости в приложении
3. Увидите круг на экране камеры (диаметр ~90 пикселей)
4. Расположите телефон так, чтобы шайба **точно** совпала с этим кругом
5. Измерьте расстояние от телефона до шайбы линейкой/рулеткой
6. Запишите это расстояние (например, **95 см**)

### Шаг 2: Обновите константу в коде

В файле `utils/puckSpeedProcessor.ts` найдите константу:

```typescript
const CALIBRATION_DISTANCE_CM = 100; // Расстояние от камеры до шайбы в см
```

Замените `100` на ваше измеренное значение (например, `95`).

### Шаг 3: Обновите размер зоны (если нужно)

Если на вашем устройстве зона кажется слишком большой или маленькой, можете изменить размер в файле `app/puck-speed.tsx`:

```typescript
const ZONE_SIZE = 90; // Диаметр зоны в пикселях
```

## Как работает измерение

1. **Калибровка**:
   - Пользователь совмещает реальную шайбу с кругом на экране
   - Система знает: если шайба занимает 90 пикселей, то расстояние = CALIBRATION_DISTANCE_CM

2. **Запись**:
   - При идеальном совпадении → автоматический старт записи через 1 секунду
   - Пользователь выполняет удар

3. **Анализ**:
   - Система извлекает кадры из видео (каждые 0.1 секунды)
   - Детектирует шайбу на каждом кадре
   - Находит **первый кадр** с шайбой (точка A)
   - Находит **последний кадр** с шайбой (точка B)
   - Вычисляет расстояние в пикселях между A и B
   - Переводит в метры используя калибровку
   - Вычисляет время (timestamp B - timestamp A)
   - **Скорость = расстояние / время**

4. **Результат**:
   - Автоматически показывается сразу после обработки
   - Можно сохранить в профиль
   - История всех измерений сохраняется

## Точность

Точность зависит от:
- Правильной калибровки расстояния
- Качества освещения
- Контрастности (шайба черная на белом/синем льду)
- Стабильности телефона

**Рекомендация**: Измерьте расстояние несколько раз для точности.
