# Исправление push-уведомлений для сообщений

## 🐛 **Проблема**
Push-уведомления для сообщений не работали, потому что подписка создавалась для отправителя, а не для получателя.

### Анализ логов показал:
- **Отправитель**: `1bc22582-30bf-4375-9c0b-ac6132542094` (ADMIN)
- **Получатель**: `3cd6dfc5-699b-4770-90cb-572edd39a9f3`
- **Подписка создавалась для**: `1bc22582-30bf-4375-9c0b-ac6132542094` (ADMIN) ❌

## ✅ **Исправления**

### 1. **Изменена логика подписки**
**Было:** Подписка с фильтром `receiver_id=eq.${userId}` для каждого пользователя
**Стало:** Глобальная подписка на все сообщения с проверкой получателя в коде

```typescript
// Убираем фильтр - слушаем все сообщения
{
  event: 'INSERT',
  schema: 'public',
  table: 'messages'
  // Убираем фильтр - слушаем все сообщения
}
```

### 2. **Добавлена проверка получателя**
```typescript
// Проверяем, является ли текущий пользователь получателем
const receiverId = payload.new.receiver_id;
if (receiverId !== userId) {
  console.log('⏭️ Сообщение не для текущего пользователя, пропускаем');
  return;
}
```

### 3. **Улучшено логирование**
```typescript
console.log(`📱 Push токены для пользователя ${userId}:`, receiverTokens.length);
if (receiverTokens.length === 0) {
  console.log('⚠️ У пользователя нет push токенов, уведомление не отправляется');
  return;
}
```

## 🎯 **Результат**

### Теперь система:
- ✅ **Слушает все сообщения** через глобальную подписку
- ✅ **Фильтрует по получателю** в коде
- ✅ **Проверяет наличие push-токенов** у получателя
- ✅ **Логирует все этапы** для диагностики

## 🧪 **Тестирование**

1. **Отправьте сообщение** с Android устройства
2. **Проверьте логи** - должны появиться новые сообщения
3. **Проверьте push-уведомление** на iOS устройстве

### Если push не приходит:
- Проверьте, есть ли push-токены у получателя
- Убедитесь, что получатель использует development build (не Expo Go)

## 🚀 **Преимущества нового подхода**

1. **Глобальная подписка** - слушает все сообщения

3. **Лучшая диагностика** - подробные логи на каждом этапе
4. **Масштабируемость** - работает для любого количества пользователей
