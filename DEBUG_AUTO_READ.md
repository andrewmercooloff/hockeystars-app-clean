# 🔍 Отладка автоматической отметки уведомлений

## 📝 Что добавлено для отладки:

### 1. Логирование таймера:
```
⏰ Запущен таймер автоматической отметки уведомлений (5 сек)
⏰ Таймер сработал! Отмечаем уведомления как прочитанные
⏰ Обновляем счетчик уведомлений
⏰ Таймер отменен (компонент размонтирован или данные изменились)
```

### 2. Логирование функции `markAllNotificationsAsRead()`:
```
📝 Начинаем отметку уведомлений для пользователя: [user_id]
📊 Получено непрочитанных уведомлений: [count]
📋 После фильтрации actionable: [count] уведомлений
✅ Уведомление отмечено: [notification_id]
❌ Не удалось отметить: [notification_id]
✅ Успешно отмечено: [successCount] из [totalCount]
✅ Локальное состояние обновлено
```

## 🧪 Как проверить:

1. **Создайте новое уведомление** (например, измените статистику)
2. **Зайдите в раздел "Уведомления"**
3. **Смотрите терминал Expo** - должны появиться логи:
   - `⏰ Запущен таймер автоматической отметки уведомлений (5 сек)`
4. **Подождите 5 секунд**
5. **Смотрите терминал** - должны появиться логи:
   - `⏰ Таймер сработал!`
   - `📝 Начинаем отметку уведомлений`
   - `📊 Получено непрочитанных уведомлений: 1`
   - `📋 После фильтрации actionable: 1 уведомлений`
   - `✅ Уведомление отмечено: [id]`
   - `✅ Успешно отмечено: 1 из 1`
   - `✅ Локальное состояние обновлено`
   - `⏰ Обновляем счетчик уведомлений`
6. **Проверьте счетчик** - должен исчезнуть

## 🔍 Возможные проблемы:

### Проблема 1: Таймер не запускается
**Симптомы:** Нет логов `⏰ Запущен таймер`
**Причина:** `currentUser` не определен или `notifications.length === 0`
**Решение:** Проверьте что пользователь залогинен и уведомления загружены

### Проблема 2: Таймер отменяется до срабатывания
**Симптомы:** Лог `⏰ Таймер отменен` через несколько секунд
**Причина:** Изменяются `notifications.length` или компонент размонтируется
**Решение:** Проверьте что не происходит перезагрузка данных

### Проблема 3: Получено 0 непрочитанных уведомлений
**Симптомы:** Лог `📊 Получено непрочитанных уведомлений: 0`
**Причина:** Уведомления уже отмечены в БД или неправильный `user_id`
**Решение:** Проверьте в Supabase Dashboard состояние уведомлений

### Проблема 4: После фильтрации 0 уведомлений
**Симптомы:** Лог `📋 После фильтрации actionable: 0 уведомлений`
**Причина:** Все уведомления - actionable (friend_request, gift_accepted, achievement, team_invite)
**Решение:** Создайте уведомление другого типа (stats_change, photo_added, etc.)

### Проблема 5: Уведомление не удалось отметить
**Симптомы:** Лог `❌ Не удалось отметить: [id]`
**Причина:** Ошибка в `markNotificationAsRead()` - проверьте права RLS
**Решение:** Проверьте RLS policies в Supabase

### Проблема 6: Счетчик не обновляется
**Симптомы:** Все логи успешны, но счетчик остается
**Причина:** Функция `updateNotificationCount()` не работает правильно
**Решение:** Проверьте логи `updateNotificationCount()` в `_layout.tsx`
