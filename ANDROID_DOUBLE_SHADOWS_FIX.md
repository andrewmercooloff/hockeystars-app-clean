# Исправление двойных теней на Android

## 🐛 **Проблема**
На Android отображались две тени одновременно:
1. **Объемная тень** (от shadowColor/shadowOffset/shadowOpacity/shadowRadius)
2. **Плоская тень** (от elevation)

Это создавало визуальный конфликт и неестественный вид.

## ✅ **Решение**
Убрали `elevation` для Android, оставив только объемные тени через shadow свойства.

## 🔧 **Технические изменения**

### **1. Основные шайбы (puck и starPuck):**

#### **До исправления:**
```typescript
android: {
  elevation: 12, // Плоская тень внизу
  shadowColor: '#000', // Объемная тень
  shadowOffset: { width: 0, height: 4 },
  shadowOpacity: 0.6,
  shadowRadius: 6,
},
```

#### **После исправления:**
```typescript
android: {
  shadowColor: '#000', // Только объемная тень
  shadowOffset: { width: 0, height: 4 },
  shadowOpacity: 0.6,
  shadowRadius: 6,
},
```

### **2. Аватары:**

#### **До исправления:**
```typescript
android: {
  elevation: 6, // Плоская тень внизу
  shadowColor: '#000', // Объемная тень
  shadowOffset: { width: 0, height: 2 },
  shadowOpacity: 0.4,
  shadowRadius: 3,
},
```

#### **После исправления:**
```typescript
android: {
  shadowColor: '#000', // Только объемная тень
  shadowOffset: { width: 0, height: 2 },
  shadowOpacity: 0.4,
  shadowRadius: 3,
},
```

### **3. Тени на льду (iceShadow):**

#### **До исправления:**
```typescript
android: {
  elevation: 6, // Плоская тень внизу
  shadowColor: '#000', // Объемная тень
  shadowOffset: { width: 0, height: 2 },
  shadowOpacity: 0.5,
  shadowRadius: 3,
},
```

#### **После исправления:**
```typescript
android: {
  shadowColor: '#000', // Только объемная тень
  shadowOffset: { width: 0, height: 2 },
  shadowOpacity: 0.5,
  shadowRadius: 3,
},
```

## 🎯 **Результат**

### **До исправления:**
- **Android:** Две тени (объемная + плоская)
- **iOS:** Одна объемная тень
- **Проблема:** Визуальный конфликт, неестественный вид

### **После исправления:**
- **Android:** Одна объемная тень (как на iOS)
- **iOS:** Одна объемная тень (без изменений)
- **Результат:** Единообразный и естественный вид

## 🔧 **Технические детали**

### **Удаленные свойства для Android:**
- **elevation** - убрано из всех стилей
- **Причина:** Создавало плоскую тень внизу, конфликтующую с объемной

### **Оставленные свойства для Android:**
- **shadowColor** - цвет тени
- **shadowOffset** - смещение тени
- **shadowOpacity** - прозрачность тени
- **shadowRadius** - радиус размытия тени

### **Совместимость:**
- **iOS:** Без изменений (использует только shadow свойства)
- **Android:** Теперь использует только shadow свойства
- **Web:** Без изменений (использует boxShadow)

### **После исправления:**
- **iOS:** 1 объемная тень (shadow свойства)
